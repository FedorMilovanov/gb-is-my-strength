# DALL·E prompts для статьи «Римлянам 7: верующий, неверующий или человек под законом?»

**Дата:** 2026-06-02  
**Цель:** богатый визуальный ряд в стиле сайта: тёплая богословская эстетика, глубокий свет/тень, без букв в изображении, чтобы подписи добавлялись HTML/CSS.

## Общий стиль для всех изображений

Использовать как хвост почти ко всем промтам:

> warm parchment and deep umber palette, muted gold highlights, cinematic theological editorial illustration, elegant chiaroscuro, subtle grain, painterly realism mixed with symbolic composition, no modern objects, no readable text, no letters, no watermark, no logo, reverent but not kitsch, high detail, suitable for a Russian theological website

Для широких картинок: `wide 16:9 composition`  
Для узких полос: `ultra-wide banner, 21:9 composition, central negative space for overlay text but no text in image`  
Для схем: `clean editorial infographic style, symbolic, no labels, no text, simple shapes, warm parchment background`

## 15. Реальные/аутентичные изображения из интернета — что можно поискать

Пока для Рим. 7 нет необходимости в обязательных внешних изображениях, но если нужен академический слой, можно искать только public domain / open access:

1. **Codex Sinaiticus / Romans manuscript** — как фоновый scholarly image; проверить права British Library / Codex Sinaiticus Project.
2. **John Calvin portrait** — Wikimedia Commons, public domain.
3. **Augustine of Hippo painting** — public domain, но лучше не перегружать статью портретами.
4. **John Owen portrait** — public domain / Wikimedia.
5. **D. Martyn Lloyd-Jones photo** — осторожно: часто copyrighted, лучше не использовать без явного разрешения.
6. **Ancient Roman law tablets / wax tablets** — public domain музейные фото могут быть полезны, но AI-символика безопаснее и единообразнее по стилю.
