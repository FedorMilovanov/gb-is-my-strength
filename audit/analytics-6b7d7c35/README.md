## Как получить одну функцию, не две синхронизируемые копии (предложение)

1. Вынести из W57 **логику, не оболочку**: расширить существующий чистый `GBReaderContract` до продуктового `getSectionMaterial(article, sectionId)`; один владелец индексирует разделы, ссылки, термины, сноски, абзацы и рисунки. Сохранить полезное распознавание неразмеченных мест Писания с мобильного. Возвращать `articleId`, `sectionId`, `sourceId`, тип и область каждого результата (раздел / другая часть статьи / редакционное пояснение). Не хранить DOM-клоны/новую базу текстов. Для идентичных ссылок в разных местах различать цитату и её вхождения.
2. Один контроллер выбранного раздела/материала, один `goToSource`: раскрывает скрытого владельца, разблокирует шторку, прокручивает и фокусирует точный источник. Для личного — существующий API библиотеки плюс её идентификаторы, с явным различием «заметка» / «помета». Не смешивать личное с авторским. Решение о размере первых N записей — в представлении, **с доступом ко всем остальным**, не усечение модели.
3. Один компонент содержимого, монтируемый один раз. Узкий хост — вкладка/диалог со свайпом, широкий — rail; меняются контейнер и управление фокусом, не алгоритм, не ссылки и не черновик. Не подгружать на телефон весь W57, не создавать параллельный CSS-патч, не перезагружать документ для смены ширины. Сначала адаптировать обе поверхности к модели на Gill II, затем проверить группировку «Ночи» и маршрут без Gill-шторки; удалить локальные экстракторы только после сверки и регрессионных контролей.
4. Приёмка: одинаковый `article + sectionId` → одинаковая упорядоченная полная модель и адреса источников на 390, 1120, 1121, 1440; одинаковый смысл пустого состояния, источники читаемы после тапа. Поворот/resize с раскрытым термином, личной записью и черновиком не создаёт вторую панель, не сбрасывает состояние. Не требовать идентичных пикселей или десктопных жестов на телефоне.
