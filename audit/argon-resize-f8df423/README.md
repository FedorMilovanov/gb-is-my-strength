# ARGON: сохранился ли абзац за шторкой после поворота?

Проверено на #2352 `f8df423a308fb3b84081bae1cd338c6d4e35a3a8`, отдельный контроль #2352 **до ARGON** `8d03615c1a13543ed6be9af6cd5939f9209b5674`. #2346 `62be8caa` не смешивался. Переиспользованы локальные статические сборки этих SHA. Chromium touch emulation, изменение viewport, не системный поворот физического телефона. Все переходы и закрытия — штатными кнопками/клавишами. Только для сопоставимого старта программно выровнен реальный заголовок `#part-controversy` у верхнего края. Без записи в хранилище или вызовов функций шторки.

## Обычная страница, без W57

Гилл II → начало «Полемика и дебаты эпохи» → «Аналитика → Писание → 2 Тим. 1:9». Повернуть с 390×844 в 740×390. Стих остаётся выбранным, фокус внутри шторки. **При простом закрытии читатель оказывается не у исходного заголовка, а ниже на двенадцать номеров абзацев.** Не путать с прежней находкой о scrollTop *самого стиха*.

| Условие | Результат после изменения размеров/закрытия |
|---|---|
| Без шторки, с hash и без него | y=7584; заголовок на +76 px, виден исходный p-037 |
| Открыта «Аналитика», Escape (с hash) или ручка (без hash) | y=10913 — старое смещение из портрета; заголовок на −3253 px, виден p-049 |
| Только «Оглавление», без входа в «Аналитику» | Тот же результат: p-049. Это общий возврат из шторки, не действие кнопки стиха |
| Повернуть и вернуть в исходную ширину **до** закрытия | p-037, заголовок на исходных +88 px |
| Вместо закрытия нажать «К упоминанию в статье» | Корректный переход к p-060 с `2 Тим. 1:9`; фокус на источнике, блокировка снята |
| Повтор основного сравнения на `8d03615` | Шторка открыта: −3253 px; закрыта: +76 px. Регрессией последнего пуша не является |

**Есть эффект и внутри «Аналитики».** Обратный поворот 740×390 → 390×844. Если панель не трогать, пока ещё показаны «Полемика и дебаты эпохи», 18 мест, `2 Тим. 1:9`. Нажать «Оглавление → Аналитика → Писание», не закрывая шторку и не прокручивая статью: появляется **«Богословские труды и итог всей жизни», 2 места, Бытие 1:2**. После Escape заголовок исходного раздела на +3428 px (далеко ниже экрана), виден p-029. Это пересчёт раздела по уехавшему под шторкой тексту, не пропажа библейских стихов.

Механизм: общий `js/site-utils.js:applyLock/releaseLock` замораживает `body` со старым отрицательным top и восстанавливает такое же числовое scrollY. После переноса строк тот же y уже не является тем же местом чтения. `GillMobileMarginalia.astro:researchData()` при повторном render выбирает H2 по его положению во viewport. **Критерий исправления:** при смене ширины без намеренной навигации сохранять идентичность исходного блока и его положение относительно читаемого окна, а не только scrollY. Сохранять общий контекст при переключении вкладок. Явный переход к упоминанию должен по-прежнему иметь приоритет над восстановлением.

## Граница 1120/1121 — другой механизм

На обычной странице при увеличении ширины всего на 1 px документ и выбранный стих сохранились, Escape возвращает фокус и p-037. С `?reader-pilot=1` bootstrap **по проекту перезагружает страницу**, меняется `performance.timeOrigin`, включается desktop W57. Нет ни старой шторки, ни зависшей блокировки; фокус на body. Исходный заголовок оказывается на −421 px **даже при закрытой шторке**, поэтому это не тот же баг блокировки. Вывод ограничен opt-in preview; не характеризует обычный desktop как перезагружающийся.
