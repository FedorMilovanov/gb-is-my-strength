**Точка исправления W60-01:** `speedSlot.ts` сейчас закрывает rail наружным `pointerdown`, что пропускает активацию через клавиатуру. Закрыть его при штатном `gb:overlay-open` для Gill TOC/настроек (или в точке общего переключения), **без эвакуации фокуса обратно на badge, если новый диалог уже принял фокус**. Это устраняет два независимых состояния и сохраняет компоновку. Тест: открыть rail вручную → Tab до нижнего TOC → Enter → один Escape; активен нижний TOC, rail закрыт, верхние «На полях» доступны. Проверить, что pointer path и Hermenevtika сохраняют поведение.

## Подтверждения по работе основного агента

- В 320/390 координатный тап по левому краю видимой метки открывает скорость без команды Play. Стрелка вправо передвигает выбор радио на `1.25×`, не запускает озвучку. Back/Home в открытой ленте видимы, не inert, центры целей доступны (44×44).
- После запуска на 1.25× горизонтальный свайп на 320/390 доходит до конца (scrollLeft=204/142), тап по `2×` не переключает воспроизведение на паузу; фактические вызовы Web Speech `[1.25, 2]`, по одному на скорость. После выбора верхняя кнопка «На полях» открывает ту же штатную шторку, Escape возвращает фокус на неё; воспроизведение остаётся `playing`.
- **W58-03 больше не воспроизводится:** вертикальная панель заменена горизонтальной. В 700×320 во время активного тестового воспроизведения `2×` уже выбрана и находится на полностью помещающейся ленте, реальный тап по `0.75×` меняет скорость (`[1.25, 2, 0.75]`) без паузы. Возвращать вертикальный поповер не требуется.
- Лично просмотрены кадры списка на 320 и дефекта контекста на Баптистах. Скриншоты и JSON остаются в `reports/w60-e567400/` (локальные артефакты). `pageerror: []` в двух скоростных и трёх панельных сценах. Это не приёмка дизайна и не закрытие блокеров Библиотеки/CI.
