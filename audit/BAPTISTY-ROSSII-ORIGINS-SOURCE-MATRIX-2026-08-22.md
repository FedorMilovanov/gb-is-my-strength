## 1. Цель волны

Эта матрица переводит нынешние три стартовые статьи из состояния «хорошо написанный ранний корпус» в состояние `BOOK-READY candidate`.

Правила волны:

1. Публичный текст не может быть сильнее доказательства.
2. Мемуар, полемический трактат, официальный рапорт и первичный участнический документ не смешиваются в один голос.
3. Категория `A1/A2/A3/B1/C/D` относится к evidence-уровню Research; `accessState`, `locatorState`, `rightsState`, `publicationState` ведутся независимо.
4. `article-ready` для изображения не означает `publication-ready`.
5. Никаких новых URL только ради того, чтобы симметрично получить «20 глав». Сначала содержательная самостоятельность.

## 9. Publication gate для Origins

Статья не считается `BOOK-READY`, если не выполнены все условия:

- нет `HOLD` claim, присутствующего как сильный declarative fact;
- каждый прямой quote имеет locator;
- каждое спорное утверждение атрибутировано своему голосу;
- 4–6 `Коротко` пунктов не содержат нового факта, отсутствующего в body;
- reading time считается из фактического body;
- 2–5 historical visuals прошли rights/provenance gate;
- cover не является placeholder SVG-only, когда documentary asset доступен;
- metadata published/updated не расходится с registry;
- search/feed/sitemap только через canonical projection;
- мобильная и desktop-версия не имеют reader-layout regressions;
- новая глава не создаёт новый URL без архитектурного решения Book Authority.

## 10. Explicit no-go list

Не делать:

- «1867 = весь русский баптизм»;
- «штунда = баптизм с самого начала»;
- «немцы принесли всё с нуля»;
- «1884 = первый съезд»;
- «1885 = начало 1944»;
- «Фетлер в 1885», пока нет первичного locator;
- копирование поздних церковных формулировок как нейтральной истории;
- массовый импорт фотографий по флагу `Article ready=YES`;
- ручная синхронизация RSS/search/sitemap;
- новые placeholder routes ради симметрии 20 глав.
