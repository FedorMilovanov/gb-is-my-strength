## 1. Вопрос владельца

«Перепроверяй все слова — не нужно ли внести новые слова в словарь ударений Vosk, улучшить качество самого Vosk? И ширину с прочими моментами ты исправил? Закрывай все вопросы без костылей».

Ответ по существу: **да, словарь был главной дырой качества**, и дыра была не в редких терминах, а в самой частой конструкции сайта — ссылках на Писание.

## 2. Что показала проверка (до правок)

### 2.1 Ссылки на Писание читались как мусор

`js/vosk-tts-worker.js` разворачивал только 16 сокращений книг (`Быт.`, `Исх.`, `Пс.`, `Рим.`, `Откр.` …). Сканирование корпуса (`src/content/**/*.mdx` + `src/components/**/*.astro`, 542 файла) дало **61** реально используемое сокращение с номером главы и стиха. Не разворачивались, среди прочего:

В статье «Оценка христоцентричной герменевтики» — **235** таких ссылок из 9 104 слов. То есть каждый четвёртый абзац заканчивался не «Римлянам 5:12», а «рим 5:12».

### 2.2 Словарь ударений покрывал не все формы

`js/vosk-custom-terms.json` (156 форм) знал `христоцентричная` и `христоцентричный`, но не знал ни одной другой формы — а в статье 151 раз встречается `христоцентричной`. Так же не были покрыты `христология/христологии/христологию…`, `христотелический`, `сотериология`, `экклезиология`, `тринитарный`, `импликация`, `эйзегеза`, `межтекстуальность`.

Отдельная находка: встроенный словарь `russian-stress-marker` (721 КБ FSA) для слова `коринфянам` отдаёт **`кор+инфянам`** — неверное ударение, которое до правки попадало прямо в синтез, потому что пользовательский словарь это слово не перекрывал.

### 2.3 Данные словаря не доставлялись после обновления

`fetch(CUSTOM_TERMS_URL, { cache: 'force-cache' })` без `?v=`: браузер обязан брать копию из кэша, не переспрашивая сервер. Даже исправленный словарь остался бы у владельца старым навсегда. Это дефект доставки, а не словаря.

## 3. Что сделано

### 3.1 Разворачивание ссылок (`js/vosk-tts-worker.js`)

- Новая таблица `SCRIPTURE_BOOKS` — **88 записей**, включая все нумерованные послания (`1 Кор.` → «первое послание Коринфянам»), книги Ветхого и Нового Завета и синонимы (`Мф.`/`Матф.`, `Мк.`/`Мар.`, `Откр.`/`Отк.`, `Притч.`/`Прит.`, `Чис.`/`Числ.`, `Ин.`/`Иоан.`).
- `CITATION_UNITS` — `гл.` → «глава», `ст.` → «стих».
- Совпадение **привязано к следующему номеру** (`(?=\s*\d)`), поэтому «Иуд. предал» и «гл. обр.» не трогаются, а «1 Кор. 13:4» разворачивается целиком: более длинные формы проверяются первыми, иначе от `1 Кор.` оставалась бы «1».
- Неразрывный пробел (`\u00A0`) нормализуется до сравнения.
- Обычные сокращения (`т.е.`, `т.д.`, `т.п.`, `т. н.`, `н. э.`, `ок.`, `напр.`, `др.`, `ср.`, `см.`) остались отдельным списком.

Проверка (функциональная, из исходника воркера):

гл. обр.       → гл. обр.      (не ссылка — не тронуто)

### 3.2 Словарь ударений (`js/vosk-custom-terms.json`, 156 → 286 форм)

Добавлено 130 форм, все — с проверкой «ровно один `+`, строго перед гласной, ключ воспроизводится снятием маркера»:

- **терминология**: все падежные формы `христоцентричн*` (+ `христоцентр+изм`, `христоцентр+ичность`), `христол+огия/христолог+ический`, `христотел+ический`, `сотериол+огия/сотериолог+ический`, `экклезиол+огия`, `тринит+арный/тринитар+изм/тринитари+анец`, `имплик+ация`, `эйзег+еза`, `межтексту+альность`;

Осознанно **не** добавлены (нет однозначного источника, «нет ударения» лучше «неверного ударения»): `Захария`, `Малахия`, `Авдия` — они в списке `STRESS_PENDING` контракта с пояснением. ### 3.4 Контракт (`scripts/tts-stress-dictionary-contract.js`)

Контракт вырос из «проверки формата JSON» в проверку **покрытия речи**:

- разбирает `SCRIPTURE_BOOKS` и `CITATION_UNITS` из воркера: точка в конце сокращения, нет дублей, расширение — произносимые слова, название книги с заглавной;
- для каждой книги последнее слово расширения обязано иметь источник ударения (словарь или marker-FSA), кроме односложных и `STRESS_PENDING`;
- сканирует **542** файла контента: любая ссылка `Аббр. N:M`, которой нет в таблице, — ошибка;
- сканирует корпус на термины-стемы (`христоцентрич`, `христологич`, `сотериологич`, `экклезиологич`, `тринитар`, `импликац`, `эйзегез`, `межтекстуальн`, `христотелич`, `христоцентризм`) и требует источник ударения для **каждой** встреченной формы;

## 4. Ширина: измерение и что изменено

Геометрия колонки владеется тремя токенами: `--gb-reader-measure` (`css/reader-preferences.css`), `--hm-article-measure`/`--hm-article-shell` (`ReaderSettings.astro`), и ограничением рельса `--hrail-readable-space` (`ReaderRail.astro`, только ≥1200px).

| Режим | Было | Стало |
|---|---|---|
| Узкая | 36rem = **576px** | 576px (не менялось) |
| Обычная | 46rem = **736px** | 736px (не менялось, это решение #2218 от 2026-10-29 по запросу «дефолт узкий какой-то») |
| Шире | 52rem → фактически **784–832px** (упиралось в `--hrail-readable-space`) | 56rem → **879px на 1280px экране, 896px на 1440px** |

Расчёт для 1280×800: `--hrail-left` 30.7 + рельс 270 + зазор 38.4 = 339.1; максимальная оболочка 927; при 56rem оболочка = 56rem + 6rem = 992 → ограничена 927 → читаемая ширина = 927 − 2×24 = **879px** (было 784).

Причина, по которой «Шире» раньше почти ничего не давало: 52rem (832) почти совпадало с 832-пиксельной оболочкой, а `--hrail-readable-space` съедал ещё 48px внутренних отступов.

Что это значит для «статья выглядит узкой»:

- если в настройках читателя стоит **«Узкая»** — это 576px, самая вероятная причина жалобы; переключатель находится в шестерёнке читателя, группа «Ширина статьи»;
- режим «Обычная» 736px — это ~80 знаков в строке, верхняя граница типографической нормы; дальше расширять по умолчанию вредно для чтения, поэтому дефолт не менялся;
- «Шире» теперь реально шире (879–896px вместо 784–832).

## 6. Что осталось открытым осознанно

1. `Захария`, `Малахия`, `Авдия` — ударение в русской традиции двоится, оставлено без маркера (`STRESS_PENDING`).
2. `греч.`, `евр.`, `лат.`, `арам.` — не разворачиваются: согласование прилагательного с существительным без разбора фразы даст «греческий слово».
3. `г.` (год) и `в.` (век) — падеж зависит от контекста («в 1950 г.» → «в 1950 году», «1950 г.» → «1950 год»); оставлено без изменений, чтобы не порождать неверную грамматику.
4. Аббревиатура `ЕХБ` читается по буквам — для названия союза это допустимо; менять на развёрнутое название означало бы менять смысл цитат.

Каждый пункт закрывается только вместе с источником (словарь ударений / разбор фразы), а не «на глаз».
