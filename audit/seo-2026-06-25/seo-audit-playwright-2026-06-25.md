- `/nagornaya/seriya/` — расширить до полноценной hub-страницы с аннотациями каждой части.

## 🟠 P1 — ВАЖНЫЕ

### P1-01: JSON-LD placeholder `{jsonLd}` на `/hard-texts/` — сломана разметка

```html
<script type="application/ld+json">{jsonLd}</script>
```

**Это буквальный нерасставленный шаблонный placeholder.** Astro-компонент передаёт переменную `{jsonLd}`, но она не рендерится. Результат: невалидный JSON, Google Rich Results Test выдаст ошибку, structured data для серии «Тайны человеческого сердца» не работает.

**Затронута:** `/hard-texts/` и вероятно другие страницы того же Astro-шаблона.

---

### P1-02: JSON-LD на `/karty/ishod/` — синтаксическая ошибка (лишний `}`)

```json
"sameAs":["https://t.me/...", "https://vk.com/curtmf"]}},{"@type":"WebSite"...
```

`]}}` — два закрывающих `}` вместо одного. `}` закрывает `sameAs`-объект Organization, второй `}` лишний — вероятно баг при ручном формировании JSON-LD или merge-конфликт в шаблоне.

**После замены `]}}` → `]}` — JSON валиден.** Структура `@graph` содержит: Organization, WebSite, WebPage, BreadcrumbList.

**Затронута:** только `/karty/ishod/` (на `/karty/avraam/` аналогичная структура валидна).

---

### P1-03: Страницы baptisty-rossii — JSON-LD `Article` без `datePublished` и `dateModified`

```json
{"@type":"Article", "headline":"...", ...}
```

Поле `datePublished` **отсутствует** на всех 10 страницах серии baptisty-rossii. Это нарушение Google Rich Results требований для Article разметки — без даты Google не показывает дату в сниппете.

**Затронуто:** `/baptisty-rossii/noch-na-kure/` и все 9 остальных статей серии.

## 🟡 P2 — ЗАМЕТИТЬ

### P2-01: 🖼️ Изображения без `alt` — системная проблема

**Масштаб:** 33 из 43 проверенных страниц имеют хотя бы одно изображение без `alt`.

**Самые проблемные:**
- `/baptisty-rossii/` + все 10 дочерних страниц: **22 изображения без alt на каждой** — это SVG-обложки серии (cover-01-kura.svg и т.д.), все без атрибута.
- Серия Gill (chast-1, 2, 3, spravochnik): **7–8 изображений без alt** на каждой.
- Повторяющийся паттерн: `data:image/gif;base64,...` (1x1 placeholder) без alt.

**Что это значит:**
1. Google Images не может индексировать эти изображения.
2. Нарушение accessibility (WCAG 2.1 A).
3. Потеря Image Search трафика — особенно критично для SVG-карт и обложек серий.

**Pattern по baptisty-rossii:** SVG-обложки в `<img src="cover-01.svg">` без `alt="Ночь на Куре — обложка серии"`. Это 10 страниц × 22 изображения = **220 изображений без alt**.

## 🔵 P3 — ЗАДЕЛЫ

### P3-01: Нет `potentialAction` (Sitelinks Searchbox) в WebSite JSON-LD — **все страницы**

```json
{"@type":"WebSite", "name":"...", "url":"..."}
```

Отсутствует `potentialAction` для Sitelinks Search Box. Это позволяет Google показывать поисковую строку прямо в SERP при брендовом запросе. Сайт уже имеет Pagefind — можно добавить:

```json
"potentialAction": {
  "@type": "SearchAction",
  "target": "https://gospod-bog.ru/?q={search_term_string}",
  "query-input": "required name=search_term_string"
}
```

---

### P3-02: Нет `hreflang` / `x-default` — все страницы

Сайт полностью русскоязычный, но `<link rel="alternate" hreflang="ru">` и `hreflang="x-default"` отсутствуют. Для Яндекса это особенно важно при геотаргетинге на Россию.

---

### P3-03: `twitter:card` — значение нестандартное на части страниц

Несколько страниц возвращают нестандартный `twitter:card` (не `summary` и не `summary_large_image`). Telegram, VK и Twitter используют этот тег для превью.

---

### P3-04: Изображения без `loading="lazy"` — Nagornaya серия

На страницах серии Нагорной проповеди hero-изображение загружается сразу (без lazy), но остальные — тоже без атрибута.

---

### P3-05: WebSite JSON-LD без `potentialAction` + `SpeakableSpecification`

`SpeakableSpecification` присутствует на baptisty-rossii страницах — это хорошо для голосовых помощников. Но отсутствует на основных статьях (Gill, Нагорная, Антисоветы).
