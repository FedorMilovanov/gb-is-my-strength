## Активная ссылка частично скрыта на 390

Пройти ArrowRight от первой до последней ссылки; после каждого шага дать полке 320 мс. На 390×844 обрезан именно **текст**, не только отступ кнопки: у «Деян. 20:17» за границей rail 22 px текста, у «Тит. 1:5–7» 12 px. На конце Home/End даёт видимую «Втор. 33:8». Но если перейти «Оглавление → Аналитика» и раскрыть «Писание» заново, выбор остаётся верным (**18 / 18**), в rail видны только **62 из 104 px кнопки**, последние 12 px текста вне окна. Повтор через закрытие всей шторки даёт тот же результат. Это не потеря выбранного стиха: заголовок области чтения целиком верен. На 320/740 отсечения текста в тех же сценариях нет. При проверке исправления учитывать итоговые размеры со стрелками после открытия `details` и финальную позицию после CSS scroll-snap, а не только значение, записанное в `rail.scrollLeft` внутри render.

- Один горизонтальный свайп по полке (320/390/740): scrollLeft с начала → 95/211/216, шторка открыта, статья и выбранное место не меняются. Это проверка самой полки, не свайпа по фону глоссария.

Для каждого места **текст и атрибуция** равны значению для этой ссылки в проекции страницы. Home/End возвращают первое/последнее. Не проверка прав или качества перевода вне опубликованных данных.
- Гилл III `#sec-method`: **одна** кнопка для «Рим 12:6»/«Рим. 12:6», но два настоящих возврата, в p-022 и p-023. `#sec-quiz` → 1 Тим 2:4 → p-013, p-065 и p-071 (последнее — `li` списка литературы). Все 5 переходов закрыли шторку, сфокусировали нужное видимое упоминание; top=144 px после завершения прокрутки. Номер в id не означает, что элемент обязательно тег `p`.

## Воспроизведение

`research/reader-w57-audit/analytics/argon-shelf.mjs` → `shelf.jsonl` (ожидается exit 1 на этом SHA); `argon-return.mjs` → `return.jsonl` (exit 0). `READER_URL` — origin точной сборки, `PLAYWRIGHT_MODULE` и `CHROMIUM_PATH` при нестандартной установке; `SHOTS` — существующий каталог для снимков. Продуктовый код не изменён.
