## Editorial grammar
Use existing journal tokens (paper, ink, gold, rule, muted) and canonical serif/body/UI font roles. The dominant story has the largest headline and optional approved illustration; supporting analysis is a distinct column or flow, not a repetitive grid. A brief is text-first. Never create empty rubrics, invented dates, counts or placeholder coverage in production. Use existing metadata and verified routes; no parallel content registry. Media is optional and must have intrinsic dimensions, accessible description, editorial caption, rights clearance and correct responsive sizes from the caller. A renderer cannot authorize publication. A draft may omit media; do not fabricate evidence. Keep DOM and visual reading order aligned. A title link is a single keyboard target; no nested links or clickable decorative containers. All variants inherit native light/dark tokens and preserve text without JS. Print uses white paper, no decorative cards, keep headings with text; verify real A4 and Letter pagination. Long Cyrillic titles, 320px, text scaling, forced colors, keyboard, print and three engines are release gates.
