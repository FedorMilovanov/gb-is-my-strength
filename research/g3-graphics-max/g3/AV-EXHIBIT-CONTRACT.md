## Composition
A compact journal figure placed beside the paragraph it supports, not a separate article or carousel. Desktop: 16:9 documentary frame (only approved actual recording capture) alongside restrained quotation typography; mobile: frame above quotation in source order, no cropped speaker or caption. Eyebrow identifies year/event; name and session title directly beneath quotation; a concise caption records source, exact frame timestamp and credit separately from excerpt interval. Timecode link opens original recording; no embed/autoplay. Existing journal paper/ink/rule/serif/ui tokens; no colored promotional button, no independent theme. Print: retain quote, attribution, original recording URL and interval, frame if approved; monochrome-friendly, natural page breaks. Without approved frame, use compact text-and-time-link figure, no fake placeholder or empty media well. No verified timed excerpt: do not render this component; accepted written-source paraphrase remains ordinary article text with written-source citation.

## Proposed normalized read-only view (parent adapts existing accepted manifest)
- sessionId, excerptId: stable IDs from Research, not locally minted authority.
- speaker, event, sessionTitle, sessionDate: verified metadata; no inferred date.
- startMs, endMs: integer, 0 <= start < end <= recording duration when known; exact original recording URL and verified time-link provided by Research, never built from a similarly titled mirror. Visible label mm:ss–mm:ss or h:mm:ss as appropriate; link names speaker/session/interval.
- originalQuote and translatedQuote: independently reviewed short exact English excerpt and faithful Russian translation; display Russian as translated speech, original clearly labeled (optional native disclosure); no words from ASR alone. Separate contextual paraphrase, never in quotation marks. Quote rights and audio verification status independently accepted.
- frame optional: local approved asset URL, width/height, informative alt, timestampMs, source/recording identity, crop and credit, hash, frame reuse clearance. Same session/recording; contextual frame can differ from exact quoted instant. If missing or not approved, omit image entirely. Embedding rights not inferred from frame rights.
- canonical claim/source links and publication decision: parent passes adopted references, component does not invent them or create its own registry. Unique citation id per occurrence and existing JournalSourceReturn when local bibliography applies. No evidence status promoted by display code.
- Internal fixture only: clearly marked synthetic test tokens, no real person's attributed invented words, no made-up footage, no public route registration. Production props fail closed if required approvals/identities absent.
