# Русский баптизм — исходный React/Vite проект

**Источник истины для следующих сборок `_app`:** этот каталог, а не старый архив ZIP и не минифицированный HTML.

## Происхождение

Восстановлен из исходного архива пользователя `react-vite-tailwind` (Drive ID `1tSV6l2CVl7MaPBWHNvf0Vt33JKUxDrJQ`) с наложением более поздних подтверждённых исходников, хранящихся в `../MindMap3D.tsx`, `../Navigation.tsx` и `../source-snapshot/`. Реконструкция выполнялась отдельно от действующего бандла. Архив сам по себе не является свежей версией приложения.

В исходниках восстановлены выпущенные параметры 3D-физики: `warmupTicks=150`, `cooldownTicks=220`, `cooldownTime=7000`, а также материалы MindMap и навигации. Горизонтальные входные анимации временных шкал, исследовательских и архивных карточек, QuizHub заменены вертикальными в соответствующих React-компонентах. Это устраняет причину выхода за экран, не добавляя глобальный `overflow-x:hidden`.

Три видимые записи временной шкалы (1869 и две 1884) приведены к опубликованному тексту бандла для сохранения исторического содержимого при технической пересборке. Расширенные источниковые поля и данные маршрутов сохранены; исторические редакционные уточнения требуют отдельной проверки по первоисточникам.

## Повторяемая сборка

```powershell
cd _build-tools/konfessii-baptizm/reconciled-app
npm.cmd ci --no-audit --no-fund
npm.cmd run build
```

Результат: единый автономный `dist/index.html` от Vite singlefile. **Не редактировать этот HTML вручную.** Перед размещением по пути `konfessii/russkij-baptizm/_app/index.html` сравнить DOM/тексты и реальные сценарии браузеров со старой сборкой. Проверить 17 разделов, 90 кнопок, переходы, навигацию, временные шкалы, Quiz, WebGL, темы, 320/390/768/1024/1440 px, Chromium/Firefox/WebKit. Горизонтальное переполнение проверять внутри iframe по `document.body.scrollWidth - document.documentElement.clientWidth`, не только снаружи.

Обязателен `npm run konfessii:audit` с `KONFESSII_AUDIT_REQUIRE_BROWSER=1` и `KONFESSII_AUDIT_REQUIRE_DIST=1`, затем production-like сборка сайта. Поддержку браузера Chrome на Windows см. в `../README.md`. Не считать зелёным аудитор, который пропустил живой браузер.

## Источники и права

Приложение ссылается на архивные и исторические материалы. Изображения, факсимиле, исторические тексты и правовые оговорки не менять ради геометрических проверок. Исходный архив хранится отдельно в Drive; его не следует повторно считать свежим источником без сравнения ревизий.

**Безопасность AI:** исходник `src/services/gemini.ts` читает `VITE_GEMINI_API_KEY`. Значение переменной при сборке Vite попадёт в клиентский JS, поэтому **не передавать сюда реальный секрет**. Для работающего AI-сервиса требуется отдельно спроектированный серверный прокси; текущая публичная сборка не содержит API-ключа.
