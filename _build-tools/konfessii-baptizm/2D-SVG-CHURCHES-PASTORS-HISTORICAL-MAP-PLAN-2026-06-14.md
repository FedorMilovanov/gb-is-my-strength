# 2D/SVG-атлас церквей, пасторов и исторических закрытий ЕХБ

Дата: 2026-06-14  
Статус: черновой план / ТЗ.  
Связано с: новой 3D-картой русского баптизма, серией `/baptisty-rossii/`, исследованием гонений и самиздата.

---

## 0. Зачем нужен отдельный 2D/SVG-атлас

3D-карта хороша для большой истории: истоки, маршруты, союзы, гонения, самиздат, ключевые люди. Но если добавить туда все церкви и пасторов, карта станет нечитаемой.

Поэтому лучше сделать **двухуровневую систему**:

1. **3D-карта** — крупные исторические узлы, маршруты, эпохи, гонения, документы, фото.
2. **2D/SVG-атлас** — более точная карта церквей, пасторов, региональных объединений, закрытых молитвенных домов, действующих общин и спорных точек.

2D/SVG-атлас можно встроить как отдельный режим в раздел карты или отдельную вкладку:

- `3D История`;
- `2D Атлас церквей`;
- `Гонения / закрытия`;
- `Пасторы / служители`;
- `Источники / уровень доверия`.

---

## 1. Главный редакционный принцип

Нельзя делать вид, что мы уже знаем полную карту всех баптистских церквей России/СССР. Это очень сложно:

- общины меняли названия;
- часть общин была незарегистрированной;
- советские документы могли скрывать или искажать данные;
- церковные списки могли быть неполными по соображениям безопасности;
- современные каталоги часто смешивают РС ЕХБ, МСЦ, независимые церкви и эмигрантские/русскоязычные общины;
- адреса и пасторы меняются;
- публичные персональные данные пасторов нужно использовать осторожно.

Поэтому карта должна иметь **режим уверенности**, а не претендовать на абсолютную полноту.

## 2. Уровни точности для церквей

### Level 1 — региональный heatmap

Использовать, когда есть только количество или уверенность по региону:

- область / край / республика;
- примерное число общин;
- период;
- источник.

Пример:

```json
{
  "region": "Ростовская область",
  "period": "современность",
  "countApprox": 40,
  "confidence": "C",
  "source": "каталог/публичный список; требует сверки"
}
```

### Level 2 — городская точка

Использовать, когда известен город, но нет точного адреса или адрес не стоит публиковать:

- город;
- название общины;
- объединение;
- статус: active / historical / closed / unknown.

### Level 3 — адресная точка

Использовать только если адрес публично опубликован на официальном сайте общины/объединения или в церковном каталоге.

### Level 4 — историческая карточка

Для закрытых молитвенных домов, домов союзов, типографий, лагерей, судов:

- место;
- дата;
- что произошло;
- кто связан;
- источник;
- уровень A/B/C/D;
- «что ещё ищем».

## 3. Статусы общин / точек

```ts
export type ChurchStatus =
  | 'active'          // действует сейчас, публично подтверждено
  | 'historical'      // историческая община / дом / центр
  | 'closed'          // закрыто властями / прекратило существование
  | 'merged'          // вошла в другую общину/союз
  | 'underground'     // подпольная/незарегистрированная, точный адрес скрывать
  | 'unknown';        // требуется проверка
```

### Цвета

- `active` — зелёный / бирюзовый.
- `historical` — золото / сепия.
- `closed` — красный / тёмный бордовый.
- `merged` — синий.
- `underground` — фиолетовый / пунктир.
- `unknown` — серый.

---

## 4. Источниковая шкала

- **A** — официальный церковный каталог, архивный документ, адресный список времени события, государственный акт, судебный документ, бюллетень времени события.
- **B** — научная статья, энциклопедия, проверяемая публикация с источниками.
- **C** — мемуары, церковная память, поздний сайт, интервью.
- **D** — сигнал: форум, соцсети, неподтверждённый список, агрегатор без дат.

На карте показывать бейдж:

- `A` — твёрдо;
- `B` — проверено по публикации;
- `C` — церковная память / требует сверки;
- `D` — не выводить в публичный режим по умолчанию, только в исследовательском.

## 6. SVG-карта: как лучше сделать

### 6.1. База

Лучше использовать SVG-карту России/Евразии с регионами:

- Россия по субъектам РФ — для современного слоя;
- Российская империя / СССР — для исторического слоя;
- отдельная врезка Кавказ / Тифлис;
- отдельная врезка Южная Украина / Таврия / Одесса;
- отдельная врезка Петербург / Москва.

Если делать в рамках существующего 3D-приложения:

- 3D world map остаётся фоном;
- поверх неё можно включать плоский SVG-overlay с регионами;
- при клике на регион — открывать 2D-панель с церквями.

### 6.2. Слои SVG

1. `regions-base` — регионы.
2. `churches-active` — действующие общины.
3. `churches-historical` — исторические общины.
4. `closures` — закрытые молитвенные дома / конфискации.
5. `pastors` — служители / маршруты служения.
6. `persecution` — аресты / суды / психбольницы / дети.
7. `samizdat` — типографии / перевозка литературы / бюллетени.
8. `confidence` — штриховка / прозрачность по уровню источника.

### 6.3. Визуальные обозначения

- Действующая церковь: круг с маленьким крестом / домом.
- Историческая община: золотой круг с датой.
- Закрытая община: красный круг с диагональной чертой.
- Подпольная группа: фиолетовый пунктирный круг.
- Пастор: маленький портретный силуэт / точка с линией служения.
- Типография: иконка листа / печатного станка.
- Психбольница: красный ромб с медицинским крестом, но осторожно и без сенсационности.
- Отобрание детей: маленький семейный значок, только если источник достаточно твёрдый.

## 7. Что показывать пользователю

### 7.1. Режим «Современные церкви»

Показывать только публично подтверждённые адреса.

Фильтры:

- РС ЕХБ;
- МСЦ ЕХБ;
- независимые;
- неизвестно / требует сверки.

Поля карточки:

- название;
- город;
- объединение;
- сайт / публичный источник;
- дата последней проверки;
- уровень источника.

### 7.2. Режим «Исторические общины»

Показывать:

- Тифлис;

## 8. Источники для стартового сбора данных

### Современные публичные каталоги

- `map.drevolife.ru/denominaciya/rs-ehb` — агрегатор церквей РС ЕХБ; использовать как C/D, требует сверки.
- `nrc-ebf.eu/ru/` — адреса церквей ЕХБ России; использовать как C, требует сверки по официальным сайтам.
- `moscowbaptist.ru` — Московское объединение церквей ЕХБ; для Москвы может быть B/C, если данные актуальные.
- `ocehb.ru/new-contacts-all` — Санкт-Петербург и Ленинградская область.
- `rusbaptist.stunda.org/adresa.html` — исторический/церковный адресный список, статус актуальности проверять.

### Исторические источники

- `Братский Вестник` 1945, 1963, 1992.
- `Бюллетень Совета родственников узников ЕХБ`.
- `Вестник спасения` / `Вестник истины`.
- История ЕХБ в СССР / Савинский / Потапова / Белякова / Никольская.
- Архивные и правозащитные публикации.

### Статистика

- Baptist World Alliance — для официальной современной статистики по РС ЕХБ.
- Euro-Asiatic Federation — для более широкого постсоветского корпуса.
- Данные РС ЕХБ / МСЦ ЕХБ — только с датой и корпусом подсчёта.

## 9. Как верифицировать поэтапно

### Этап 1 — грубая карта регионов

- собрать регионы и примерное количество общин;
- не публиковать точные адреса;
- отметить всё как `C/D`, пока не проверено.

### Этап 2 — города

- проверить города по 2 независимым источникам;
- добавить координаты города, не адреса;
- выделить исторические и современные точки.

### Этап 3 — адреса

- добавлять только публичные адреса с официальных сайтов;
- дата проверки обязательна;
- не собирать телефоны и персональные контакты без необходимости.

### Этап 4 — пасторы

- исторические служители — можно показывать по исследовательским источникам;
- современные пасторы — только если публично указаны на сайте церкви/объединения;
- не показывать личные телефоны.

### Этап 5 — закрытия / гонения

- каждое закрытие или арест — только с источником;
- если источник церковный бюллетень — указывать `A/C`;
- если есть государственный документ — повышать до `A`.

## 10. MVP 2D/SVG-атласа

Минимальная версия:

1. SVG-карта России + Кавказ + Украина/Таврия в исторической врезке.
2. 5–7 региональных кластеров:
   - Москва;
   - Петербург;
   - Кавказ / Тифлис;
   - Южная Украина / Таврия;
   - Ростов / Северный Кавказ;
   - Сибирь / ссылки;
   - Латвия / Лигукалнс.
3. 20–30 исторических точек с источниками.
4. 5 кейсов гонений.
5. 5 фото/документальных карточек.
6. Переключатели слоёв.
7. Легенда A/B/C/D.

Не начинать MVP с попытки нанести 1500+ современных общин. Это утопит карту и верификацию.

## 11. Связь с 3D-картой

2D/SVG-атлас можно сделать как:

### Вариант А — вкладка внутри 3D-карты

Плюсы:

- единый раздел;
- общие данные;
- пользователь не уходит.

Минусы:

- усложнение приложения;
- нужно аккуратно оптимизировать.

### Вариант Б — отдельный iframe/страница

Например:

```text
/konfessii/russkij-baptizm/atlas/
```

Плюсы:

- можно сделать чистый SVG/HTML без тяжёлого 3D;
- легче поддерживать;
- лучше для мобильных.

Минусы:

- отдельная навигация;
- нужно синхронизировать данные.

### Рекомендация

Сначала сделать **отдельный SVG-атлас** как прототип, затем встроить переход из 3D-карты.

## 12. Что не делать

- Не публиковать «полную карту всех баптистских церквей России», пока нет проверки.
- Не смешивать РС ЕХБ, МСЦ, независимые и исторические общины без фильтра.
- Не показывать современные адреса незарегистрированных/чувствительных групп без публичного источника.
- Не использовать современные фото людей/церквей без прав.
- Не превращать гонения в визуальный «эффект» без источника и уважительного тона.

## 13. Следующий практический шаг

Создать исследовательский CSV/JSON-прототип:

```text
baptisty-rossii/research/map-data/church-points-draft.csv
```

Поля:

```text
id,name,status,tradition,period,region,city,address_public,lat,lon,precision,source_level,source_url,notes,next_search
```

Начать не с 1500 общин, а с 30–50 точек:

- исторические узлы;
- известные закрытия;
- ключевые современные публичные центры;
- региональные объединения.

## 14. Главный вывод

Да, карту церквей и пасторов можно делать. Но профессионально — только как **проверяемый SVG-атлас с уровнями уверенности**, а не как псевдоточная карта.

Лучший путь:

1. 3D-карта — большая история и маршруты.
2. 2D/SVG-атлас — церкви, пасторы, закрытия, адреса, регионы.
3. Гонения — отдельный слой, не приложение к истории.
4. Фото и документы — только с правами и источниками.
5. Всё спорное — с бейджем `требует сверки`.
