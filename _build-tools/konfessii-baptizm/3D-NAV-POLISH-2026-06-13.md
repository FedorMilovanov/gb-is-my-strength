# 3D-приложение: навигация верхней панели — анти-оверлап (2026-06-13)

По скринам владельца верхняя nav-панель на первом экране могла сжиматься так, что бренд «Русский баптизм / карта истории» визуально наезжал на пункт «Главная».

## Что изменено в React-исходнике

Файл источника: `src/components/Navigation.tsx` из Drive/Vite проекта.

Локальная копия для будущих агентов: `_build-tools/konfessii-baptizm/Navigation.tsx`.

Правки:
- nav шире: `max-w-6xl` → `max-w-[82rem]`, `w-[95%]` → `w-[96%]`;
- контейнер чуть компактнее: `gap-3` → `gap-2`, `px-3` → `px-2.5`;
- бренд чуть компактнее: `gap-2.5 px-4` → `gap-2 px-3`;
- nav items компактнее и без переноса: `px-3.5 text-[11.5px]` → `whitespace-nowrap px-2.5 text-[11px]`;
- gap nav items: `gap-0.5` → `gap-0`.

Цель: не менять дизайн, а убрать overlap без скрытия разделов и без превращения nav в горизонтальный скролл.

## Проверка

После правки пересобрать `_app/index.html` из Vite-проекта и прогнать:

```bash
npm run konfessii:audit
npm run validate:all
node scripts/audit-pro.js
```

Дополнительно визуально проверить ширины 1366, 1440, 1536, 1680: бренд не должен накрывать «Главная», а «Глоссарий» не должен залезать под кнопку темы.
