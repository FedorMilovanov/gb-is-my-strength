# Генератор страницы «Карта Русского Баптизма»

Dev-tooling (Node, без сборщика). Генерирует самодостаточный
`konfessii/russkij-baptizm/index.html` из структурированных данных.

## Файлы
- `data.js` — весь контент (граф, персоны, хронология, викторина, глоссарий…).
- `body.js` — рендер секций в HTML.
- `runtime.js` — inline-JS страницы (canvas-карта «созвездие», викторина, глоссарий).
- `build.js` — `<head>`, мета/OG/JSON-LD/CSP, CSS.
- `main.js` — сборка: `node main.js` → перезаписывает финальный HTML.

## Как пересобрать
```
node _build-tools/konfessii-baptizm/main.js
```
Затем обязательно: `npm run konfessii:audit` (регресс-защита, см. AGENTS §9.23).

> Финальный HTML — самодостаточный, коммитится. Прямую правку HTML избегать
> (перезатрётся сборкой); править здесь и пересобирать.
