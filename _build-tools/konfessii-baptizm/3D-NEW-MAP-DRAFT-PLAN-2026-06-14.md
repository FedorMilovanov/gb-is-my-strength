# Черновой план новой 3D-карты «Русский баптизм»

Дата: 2026-06-14  
Статус: рабочее ТЗ / инструкция для будущей пересборки карты.  
Цель: сделать карту не просто «красивым космосом», а мощным, понятным историческим инструментом: мир/Евразия, маршруты, фото, SVG-слои, гонения, документы, источники A/B/C/D и связь со статьями серии «Баптисты России».

---

## 0. Главное правило разработки

1. **Не править руками** `konfessii/russkij-baptizm/_app/index.html`.
2. Все изменения делать в исходниках карты:
   - `_build-tools/konfessii-baptizm/MindMap3D.tsx`;
   - `_build-tools/konfessii-baptizm/source-snapshot/data/timeline.ts`;
   - при необходимости новые data-файлы в исходнике приложения.
3. После изменений — пересборка Vite singlefile-приложения и только потом замена `_app/index.html`.
4. Любое событие карты должно иметь:
   - год / диапазон;
   - слой;
   - краткое описание;
   - источник / уровень источника;
   - ссылку на статью или research-досье;
   - если факт спорный — явную пометку.

## 1. Концепция: карта мира + исторические слои

Базовая сцена:

- 3D-глобус / полусфера / плоско-изогнутая карта мира на `world-atlas/countries-110m.json`, как текущая 3D-карта.
- Основной фокус камеры: Евразия, но мир виден шире, чтобы показать:
  - Германия / Гамбург / Онкен;
  - Литва / Кальвейт;
  - Кавказ / Тифлис;
  - Южная Украина / Херсонщина / Таврия;
  - Петербург;
  - Москва;
  - Сибирь / лагеря / ссылки;
  - Латвия / Лигукалнс;
  - США / Канада — эмиграция, Винс, поздняя память, но только вторым планом.

Карта должна быть устроена как **исторический атлас с включаемыми слоями**, а не как хаотичный граф.

## 2. Слои карты

### 2.1. Слой «Истоки и предыстория»

Цвет: золото / зелёный / тёплая охра.  
Смысл: показать, что русский баптизм не был только «западной прививкой», но и не возник сам по себе как готовая баптистская конфессия.

Узлы:

- Водные молокане до 1867 — Северов, Танасов, Ситников, Пришиб, Шемахинский и Ленкоранский уезды.
- 1867 — Кура / Воронин / Кальвейт / Деляков.
- 1869–1871 — Цимбал, Рябошапка, Ратушный.
- 1874 — Петербург / Редсток.
- 1884 — Петербургское совещание и Ново-Васильевка отдельно.

Обязательная подпись:

> Воронин — первый русский баптист в конфессиональном смысле; водные молокане — предыстория крещения по вере, но не готовая баптистская конфессия.

### 2.2. Слой «Союзы и официальные центры»

Цвет: синий / бирюза.  
Смысл: организационная история.

Узлы:

- 1884 — Союз русских баптистов.
- 1909 — евангельские христиане / Проханов; не объединение с баптистами.
- 1944 — ВСЕХиБ.
- 1945 — ХВЕ / Прибалтика.
- 1963 — Устав ВСЕХБ.
- 1992 — РС ЕХБ.

### 2.3. Слой «Гонения и совесть»

Цвет: красный / тёмный янтарь / угольный.  
Смысл: сделать гонения видимым слоем, а не примечанием.

Узлы:

- 1919 — декрет о замене военной службы.
- 1923 — военный вопрос / ОГПУ / XXV съезд.
- 1929–1930 — закон, НКВД, закрытия, Дом Евангелия.
- 1937 — НКВД №00447.
- Георгий Слесарев — 1935–1938.
- Иван Шилов — 1919–1937.
- Николай Хмара — 1963–1964.
- Иван Моисеев — 1972.
- 1980 — психбольницы, дети, армия, бюллетени.

Отдельный режим: **«только гонения»**. При включении:

- все остальные узлы приглушаются;
- на карте остаются красные/янтарные точки;
- справа открывается список кейсов;
- у каждого кейса видна строка: `источник: A/C`, `что ещё ищем`.

### 2.4. Слой «Самиздат и подпольная печать»

Цвет: фиолетовый / золото / бумажный.  
Смысл: печать как церковная инфраструктура.

Узлы:

- 1963 — `Вестник спасения`.
- 1964/1970 — Совет родственников и бюллетени.
- 1971 — издательство `Христианин`.
- 1974 — Лигукалнс.
- 1977 — Ивангород / печатники.
- 1980 — Донченко с бюллетенями и Евангелиями.
- 1976 — `Вестник Истины`.

### 2.5. Слой «Современность и статистика»

Цвет: белый / холодный голубой.  
Смысл: аккуратная статистика без одной «магической» цифры.

Показывать отдельно:

- РС ЕХБ;
- МСЦ ЕХБ;
- независимые общины;
- Baptist World Alliance;
- Euro-Asiatic Federation.

## 3. SVG-оверлеи поверх карты

На базовую карту мира можно накладывать SVG-слои:

### 3.1. Маршрутные линии

- Тифлис → юг Украины → Ново-Васильевка.
- Петербург → Москва → общероссийские съезды.
- Москва → лагеря / ссылки / Сибирь.
- Москва / СЦ → Латвия / Ивангород / Украина / Киргизия — сеть `Христианина`.

Линии должны быть не просто линиями, а иметь тип:

- `mission` — миссионерские связи;
- `organization` — союзная организация;
- `persecution` — ссылка/лагерь/арест;
- `samizdat` — печать/перевозка литературы;
- `memory` — память/эмиграция/архив.

### 3.2. Облака эпох

Полупрозрачные SVG-зоны:

- «Закавказье»;
- «Южная штунда»;
- «Петербургская линия»;
- «Советская ночь»;
- «Совет Церквей / Самиздат».

### 3.3. Световые метки

- Золотой пульс — исток.
- Красный пульс — гонение / смерть / арест.
- Фиолетовый пульс — подпольная печать.
- Синий пульс — официальный союз / съезд.

## 4. Фото-слой

Фото не должны быть случайной галереей. Каждое фото — исторический якорь узла.

### 4.1. Уже добавленные локальные фото

Папка:

```text
images/konfessii/russkij-baptizm/photos/
```

Файлы:

- `old-tbilisi-kura-xix.jpg` — Тифлис / Кура.
- `tiflis-bazar-baron-de-baye-1900.jpg` — Тифлисская городская среда.
- `saint-petersburg-nevsky-1800s.jpg` — Петербургская линия.
- `README.md` — источники и правовой статус.

### 4.2. Как показывать фото

Варианты UI:

1. **Filmstrip в подсказке / стартовом экране** — уже начато в `LearningCoach`.
2. **Фото-карточка в инспекторе узла**:
   - фото;
   - подпись;
   - источник;
   - правовой статус;
   - ссылка на статью.
3. **Фото как billboard в 3D-сцене**:
   - маленькая полупрозрачная карточка рядом с узлом;
   - при наведении увеличивается;
   - при клике открывает досье.
4. **Документальные карточки для гонений**:
   - не обязательно фото человека;
   - можно использовать скан бюллетеня, обложку журнала, фрагмент документа, карту лагеря.

### 4.3. Что искать для фото

Приоритет с чистыми правами:

- Дом Евангелия, СПб — историческое фото / public domain / разрешение.
- Ново-Васильевка / Таврия / меннонитские колонии — старые фото или карты.
- Москва / ВСЕХБ / Малый Трёхсвятительский.
- Сибирь / лагеря / Соловки / Карлаг / Долинка.
- Лигукалнс / Ивангород / печатники.
- Керчь / Волонтировка / Иван Моисеев — только если есть права или архивное разрешение.

### 4.4. Политика прав

- Wikimedia Commons / Public Domain / LOC — можно сохранять локально.
- Современные сайты / мемориалы / частные фото — сначала фиксировать ссылку и статус, не копировать без разрешения.
- Если фото важно, но права неясны — в карте делать ссылку, а не локальную копию.

## 6. UX новой карты

### 6.1. Стартовый экран

Не просто «Начать исследование», а выбор режима:

- «Понять истоки»;
- «Увидеть гонения»;
- «Проследить самиздат»;
- «Смотреть всё».

Каждый режим имеет:

- цвет;
- краткое объяснение;
- 2–3 фото;
- кнопку «начать маршрут».

### 6.2. Инспектор узла

Карточка узла должна иметь структуру:

1. Фото / документ / карта.
2. Название.
3. Год и место.
4. Слой.
5. Источник A/B/C/D.
6. Короткая история.
7. Что спорно / что ищем.
8. Ссылка на статью.
9. Ссылка на research.

### 6.3. Timeline

Timeline должен быть крупнее и яснее. Вехи:

- 1840–1850-е — водные молокане;
- 1867 — Кура;
- 1884 — два события;
- 1919 — декрет совести;
- 1929 — закон;
- 1937 — террор;
- 1944 — ВСЕХиБ;
- 1961 — Инициативная группа;
- 1966 — майская делегация;
- 1971 — `Христианин`;
- 1972 — Моисеев;
- 1980 — бюллетени / дети / психбольницы;
- 1992 — РС ЕХБ.

### 6.4. Мини-карта / легенда

Всегда видимая легенда:

- золото — истоки;
- синий — союзы;
- красный — гонения;
- фиолетовый — самиздат;
- белый — современность;
- A/B/C — уровень источника.

## 7. Визуальный стиль

Карта должна быть «топовая», но читаемая:

- тёмный космос / глубокий синий фон;
- золотые линии истоков;
- красные линии гонений как трещины / шрамы;
- фиолетовые линии самиздата как сеть печати;
- фото в сепии / чёрно-белом, с мягким свечением;
- документы — как бумажные карточки с тенями;
- при выборе слоя остальные слои уходят в туман.

### Эффекты

- мягкий glow вокруг активного узла;
- line trail при маршруте;
- photo parallax в карточке;
- document flip для бюллетеней;
- snow/noise overlay для советской ночи;
- red pulse для событий гонений;
- gold pulse для истоков.

Но: всё должно иметь `prefers-reduced-motion` fallback.

## 8. Производительность

- Фото оптимизировать: webp/avif для больших, jpg только если уже маленький.
- Для preview использовать 300–600 px, не оригиналы по 5–20 MB.
- Lazy load в инспекторе.
- На mobile — не показывать 3D-billboard сразу, только карточки.
- Ограничить количество одновременно видимых фото.

## 11. Главное редакционное резюме

Новая 3D-карта должна быть не «аттракционом», а исторической навигацией:

- человек видит мир и маршруты;
- понимает, какой слой включён;
- видит фото или документ;
- понимает уровень источника;
- может перейти в статью;
- видит, где факт спорный;
- не теряет человеческие судьбы за организационной историей.

Особенно важно: **гонения должны стать отдельным читаемым слоем**, а не случайными красными точками.
