# Личная библиотека v3 — проектирование и проверка

Дата: 2026-11-06. Область: gospod-bog.ru, личные записи читателей.

## Принципы
- Ни аккаунтов, ни облачного сервиса, ни обязательных платежей.
- Старые записи остаются в ключах gb-highlights-v1, gb-reader-notes-v1, gb-favorites.
- Операции сохранения/удаления избранного идут через GBFavoriteStore, а не его обход.
- Метки, статусы чтения и повторения — отдельные gb-library-tags-v1, gb-library-reading-v1, gb-library-revisit-v1.
- Публичные API GBHighlights и GBReaderLibrary сохранены.

## Чтение
- «Читаю»: только явный выбор. Запоминается ближайший заголовок с ID и запасной процент прокрутки.
- «Прочитано»: окончательный статус, не предлагается снова.
- «Не интересно»: окончательное исключение, не предлагается снова.
- Архив завершённых и отклонённых статей в меню позволяет вернуть запись в «Читаю».
- Уход на другую страницу и возврат к позиции через одноразовую сессионную метку.
- Нет автоматического «Прочитано» по достижении конца.

## Перечитать сегодня
- Одна детерминированно выбранная цитата в день, без напоминаний.
- Можно скрыть карточку на день или навсегда исключить конкретную цитату.
- Никакого изменения или удаления оригинальной цитаты.

## Исследование
- Вкладка «Источники» группирует записи по исходной странице.
- Метки по отдельным записям, локальная фильтрация и поиск с частичной поддержкой русских словоформ.
- Новые цитаты могут сохранить короткий контекст до и после выделения.
- Новые, старые и алфавитные сортировки, подсветка совпадений, пустые состояния.
- JSON-копия: цитаты, заметки, избранное, метки, чтение, исключения.
- Импорт проверяет формат, типы, ссылки, размеры и лимиты, добавляет без перезаписи и проверяет дубликаты.
- При отказе записи откатываются уже записанные ключи. Истинная транзакция между localStorage ключами невозможна; при одновременной блокировке записи и отката для восстановления может потребоваться резервная копия.

## Визуал и доступность
- Десктопный диалог адаптивной высоты, мобильная шторка.
- Сохранены три цветовые темы и reduced-motion.
- Клавиатурная навигация, фокус, доступные названия элементов, корректная работа при масштабировании.
- Не считать E2E тесты полной сертификацией WCAG.
