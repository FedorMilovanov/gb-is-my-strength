# BUILD_TIME_STRANGLER_ARCHITECTURE_2026.md — build-time strangler для GitHub Pages

Дата: 2026-06-12

---

## 1. Проблема

Классический strangler pattern использует runtime facade/proxy:

```text
request → facade → legacy or new system
```

Но GitHub Pages — static hosting. Там нет runtime proxy.

Значит нужен другой вариант:

```text
build-time facade
```

---

## 2. Build-time strangler

На этапе сборки решаем:

```text
какие URL уже генерируются Astro;
какие URL пока копируются из legacy;
какие assets нужны обоим.
```

Результат:

```text
dist/ = полный сайт
```

Пользователь и поисковики не знают, какая страница legacy, а какая Astro.

---

## 3. Ownership manifest

Нужен файл:

```text
migration/page-ownership.json
```

Пример:

```json
{
  "/about/": "astro",
  "/articles/kod-da-vinchi/": "legacy",
  "/karty/avraam/": "legacy",
  "/dev/astro-test/": "astro"
}
```

---

## 4. Copy algorithm

```text
1. Run astro build → dist generated with Astro-owned pages.
2. Copy all static shared assets to dist.
3. For every legacy HTML URL not owned by Astro, copy old file to matching dist path.
4. Do not overwrite Astro-owned files.
5. Copy system files: CNAME, robots.txt, verification, manifest, sw if still needed.
6. Validate dist.
```

---

## 5. Files that must always be copied until replaced

```text
images/
fonts/
icons/
favicon*
apple-touch-icon.png
CNAME
robots.txt
manifest.json
sw.js initially
feed.xml until generated by Astro
sitemap.xml until generated by Astro
verification files
css/ and js/ while legacy pages exist
```

---

## 6. Validation after build-time strangler

Run contract extraction on dist:

```bash
node scripts/extract-url-contract.js --root dist --out reports/dist-contract.json
node scripts/compare-url-contract.js reports/url-contract-baseline.json reports/dist-contract.json
```

Check:

```text
[ ] every public URL exists
[ ] canonical unchanged
[ ] no accidental noindex
[ ] h1 count == 1
[ ] sitemap/feed present
[ ] assets exist
```

---

## 7. Why this is safer

```text
No runtime hosting change.
No proxy needed.
GitHub Pages still serves static files.
Astro can gradually own more pages.
Rollback = revert ownership manifest or PR.
```

---

## 8. Risk

```text
copy script may overwrite Astro pages;
assets may be missed;
sitemap/feed may become inconsistent;
legacy CSS/JS still carried until migration complete;
```

Mitigation:

```text
ownership manifest;
no-overwrite rule;
dist contract compare;
asset/link validation;
small page batches.
```

---

## 9. Do not implement until

```text
[ ] Astro scaffold works
[ ] /about/ Astro pilot works locally
[ ] extractor supports --root/--out
[ ] baseline contract frozen
```

## 10. Итог

For GitHub Pages:

```text
Strangler migration must be build-time, not runtime.
```
