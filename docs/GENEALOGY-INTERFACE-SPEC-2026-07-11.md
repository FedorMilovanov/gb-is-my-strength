## 1. Три главные цели (не терять «изначально»)

Референс кричит о трёх вещах — это и есть ядро продукта, всё остальное вторично:

1. **Карта ОГРОМНАЯ и зумируемая.** Мини-карта справа сверху показывает viewport-рамку
   как малую часть большого поля узлов. Пользователь видит обзор (ключевые узлы) и
   **приближает** до любой персоны. НЕ статичная схема — исследуемое пространство.
   → Полный универсум ~3056 персон; на обзоре видно ~24 крупных, при зуме раскрываются.
2. **Семантический зум: сжатая группа → раскрытие.** У кластеров на обзоре — «веер из
   точек» + «+N имён»/«множество имён» (легенда ref 04: «Сжатая группа (множество
   имён)»). При приближении/клике группа **раскрывается** в реальные узлы-персоны.
   → Это ZMLT: карта превращается в детальную при приближении (engine-contract §2).
3. **Фокус на линии.** Можно выбрать линию/персону («Фокус: линия Давида») — она
   подсвечивается золотом, всё остальное **приглушается** (серым). Мгновенно видно
   «как эта ветвь идёт ко Христу». Сброс — «Сбросить фокус».
   → degree-of-interest / фокус-линия предки+потомки (engine-contract §6).

Всё остальное (панели, фильтры) — обслуживает эти три цели. Планка: **не «схема», а
удобнейшее исследуемое пространство** (слова владельца: «SVG шедевр удобнейший»).

## 2. Анатомия интерфейса (по ref 04, поэлементно)

Раскладка: **левая колонка (эпохи) · центр (карта) · правая панель (навигация) ·
низ (легенда) · нижний-левый угол (глоб. контролы)**.

### 2.1 Верхняя панель (над картой)
- **Заголовок** «Генеалогия Спасителя» + подзаголовок «От Адама до Христа Спасителя»
  (курсив, золото). Слева — круглый лого-медальон с древом.
- **Индикатор масштаба** (обзор): бейдж «Обзорный масштаб · показаны только ключевые
  узлы» с иконкой глаза. Меняется по уровню зума (L0/L1/L2).
- **Действия справа:** обзор — «Поделиться» (URL-состояние) + «Сохранить вид»;
  фокус-режим — чип «Фокус: <линия>» с «×» + кнопка «Сбросить фокус».
- **«?»** — помощь/онбординг.

### 2.2 Левая колонка — эпохи (навигация по времени)
Вертикальный список 6 эпох, каждая: иконка + название + диапазон книг. По ref:
- Сотворение · Бытие 1–5
- Потоп · Бытие 6–9
- Патриархи · Бытие 10–50
- Царство · 1–2 Царств
- Плен · Иеремия, Даниил
- Исполнение · Евангелия
Клик по эпохе → **прыжок/центрирование** карты на этой эпохе (jump-to-anchor).
Активная эпоха подсвечена. Внизу — «О проекте · Методология, источники и принципы».
Колонка сворачивается («»»). Наш data: `eras.json` (8 внутренних эпох → сгруппировать
в 6 читательских ярлыков или показать все 8 — решение контента).

### 2.3 Правая панель — навигация и управление
- **Мини-карта** («Карта (мини-карта)»): уменьшенная схема всего графа + рамка
  текущего viewport (draggable). Подтверждает масштаб. Обязательна.
- **Зум-контролы:** «−  100%  +», fullscreen, «прицел» (re-center на хребет).
- **Поиск:** «Найти имя, место, ссылку…» — по имени (ru/he/gr/translit), месту, стиху.
  find-as-you-type → центрирование + подсветка (engine-contract §6).
- **Фильтры:**
  - «Все линии ▾» — фильтр по родословной линии (мессианская/Мф/Лк/народы/…).
  - «Все периоды ▾» — фильтр по эпохе.
  - «Только имена» / «Только ключевые узлы» — toggle: скрыть кластеры-агрегаты, оставить
    именованные узлы (или наоборот — показать только якоря).
  - «Скрыть пустые» — скрыть персон без связей (у нас ~980 изолированных — evidence).
- **Быстрые ссылки** (saved views — сохранённые виды): по ref —
  Адам → Иисус Христос · 12 колен Израиля · Дом Давида · Матфей 1 · Луки 3 ·
  **Женские фигуры** · **Опорные места** · **Хронология событий**.
  Клик → applyView (viewport + фильтр + фокус). Наш data: `views.json` (Phase 1.5).
- **Данные (атрибуция):** «Данные: Священный текст, библейские справочники» →
  у нас: Синодальный + STEPBible TIPNR (CC BY) + редакция проекта.

### 2.4 Центр — карта
Хребет (золотая мессианская нить, крупные якоря) + кластеры по бокам с **веером точек**
(сжатая группа). Линии цветом по типу (см. легенда). Узлы — карточки-лозенги с
иконкой-эмблемой + имя + подпись + счётчик. См. визуальный язык — ref 08 + наш
готовый статический эталон `data/genealogy/v2/build/genealogy-l0-preview.svg`.

### 2.5 Легенда (низ по центру)
Типы линий (ref 04/фокус): Мессианская линия · Линия патриархов/завет ·
Линия народов · Матфей: царская линия (пурпур) · Лука: через Нафана/Марию (бирюза) ·
Побочные/Каинова (рыжий) · **Пунктир — связь между линиями / супружеские связи /
другие связи** · **Сжатая группа (множество имён)** — веер точек.

### 2.6 Нижний-левый угол — глобальные контролы
Закладка (bookmark текущего вида) · «?» помощь · настройки (шестерёнка) ·
переключатель темы (солнце/луна). Тема — обязательно обе (`html.dark` контракт сайта;
пергамент — светлая база, тёмная — свой тёплый-тёмный вариант).

## 3. Фокус-режим (по присланному скрину)

Триггер: клик по персоне/линии, или быстрая ссылка (напр. «Дом Давида»), или поиск.
Поведение:
- Выбранная линия/ветвь (предки + потомки целевого узла) — **полная яркость + золото**,
  утолщённые рёбра, подсветка.
- Все прочие узлы/рёбра — **приглушены** (серый, opacity ~0.25–0.35, grayscale).
- Верхняя панель: чип «Фокус: <название линии>» с «×» + «Сбросить фокус».
- Мини-карта отражает фокус (подсвеченная траектория).
- Зум обычно повышается (100%+) — фокус ≈ приближение к ветви.
Реализация: `computeFocusLineage` (уже есть в v1-острове logic) поверх LOD;
предок-трассировка отец→…, для Христа — через Марию (кровная линия Лк).

## 4. Семантический зум — контракт уровней (интерфейсная проекция)

| Зум | Что видит пользователь | «Веер точек» |
|---|---|---|
| **Обзор (L0)** | ~24 крупных узла: хребет + мега-кластеры «+N имён». Бейдж «Обзорный масштаб». | Кластер = карточка + декоративный веер точек (намёк на содержимое). |
| **Ветвь (L1)** | Клик по кластеру / средний зум → кластер **раскрывается**: веер точек превращается в реальные узлы (радиально «12 колен» ref 06; колонкой «Мф 1»/«Лк 3»). Соседи сжимаются. | Раскрыт целевой, остальные сжаты. |
| **Персоны (L2)** | Ближний зум → полные карточки персон в видимой области, lazy-подгрузка. | Развёрнуто всё в поле зрения. |

Переход — **анимированный морфинг** (FLIP), позиции якорей неизменны (anchor
continuity). `prefers-reduced-motion` → без анимации. Бюджет видимых карточек ≤ ~500.

## 6. Состояния и взаимодействия (usability)

- **Hover** узла: лёгкий подъём/тень, tooltip (имя, стих). Курсор pointer.
- **Клик** узла: панель деталей (имя ru/he/gr, эпоха, роль, хронология MT, значение,
  спорные callouts, ссылки на Писание) — из v1 DetailPanel (перенести на движок).
- **Клик кластера:** раскрытие (L1) + при желании фокус.
- **Клавиатура:** ↑ родитель, ↓ первый ребёнок, ←→ братья, Enter детали, Esc сброс,
  `/`|Ctrl+K поиск (модель v1 — сохранить).
- **URL-состояние:** `?view=&z=&focus=&filters=` — «Поделиться»/«Сохранить вид».
- **A11y:** SR-слой (статическое оглавление), ARIA-tree, reduced-motion, контраст AA
  (Lighthouse a11y ≥95). Canvas дополняет статический слой, не заменяет.
