# Библейский Атлас — план качества карт (движок-первым)

_Создан: 2026-07 · владелец задал курс: «улучшать движок, чтобы карты были
качественные, а не писать везде всё с нуля». Порядок исполнения — за
исполнителем; ниже приоритезировано по отзывам владельца._

## 0. Философия

**Один движок — много карт.** Всё, что нужно больше чем одной карте, живёт в
`scripts/lib/sheet-engine.js` как переиспользуемый примитив, управляемый
**данными** из `karty/<slug>/route.json`. Никаких одноразовых хардкодов в
конкретную карту. База географии (`karty/_engine/base-geo.svg`) — общая для
семейства `levant`.

Каждый шаг закрывается гейтами: `atlas-data-check`, `atlas-label-audit`,
`atlas-visual-check`, `check-engine-contracts`, `validate-map-routes`, экспорт,
плюс зонды (наезды глиф↔подпись, глифы/линии на воде, обрывы рек) — и
скрин-самооценкой (макро + микроскоп).

## 1. Что не так сейчас (отзывы владельца)

1. **12 колен** — сейчас точки с подписями. Нужна карта **с границами и
   залитыми цветом уделами** (эталон `05_carte-des-tribus-d-israel`), легенда
   колен, карточки внизу, слои-темы. → **ПРИОРИТЕТ №1.**
2. **«Начало» (nachalo)** — «скудновата на вид». Народы после потопа показаны
   тремя стрелками (Иафет/Сим/Хам). Нужно богаче: зоны-заливки Книги Народов,
   имена народов, больше визуальной опоры.
3. **Нет карты «Израиль сквозь века»** — как менялась территория по эпохам, с
   временной шкалой (эталон `07_carte-historique-d-israel-et-juda`: вкладки
   Объединённая монархия → Разделённое царство → Ассирия → Вавилон).

## 2. Эталоны (docs/design-references/selected/02_maps_desktop_core/)

- `05_carte-des-tribus-d-israel.webp` — 12 колен: залитые уделы, номерные
  бейджи, границы-пунктир, легенда цветов, карточки колен, слои-темы.
- `07_carte-historique-d-israel-et-juda.webp` — Царства во времени: 4 вкладки
  эпох, залитые Израиль(син.)/Иудея(зол.)/другие(сер.), династии, слои.
- `11_interactive-map-of-ancient-israel-and-judah.webp` — то же, вариант.

Обе держатся на ОДНИХ примитивах: **территории-заливки** + **эпохи**.

## 3. Движковые примитивы (переиспользуемые)

### E1. Территории — регионы-заливки `route.regions[]` ⭐ фундамент
Новый примитив: залитый полигон удела/царства с границей и подписью.
```
regions: [{
  id, name, badge?,            // «Иуда», номер 1
  d: "M.. L.. Z",              // полигон в юнитах листа (levant grid)
  tint: "judah",               // ключ палитры (см. ниже) ИЛИ hex
  labelPos:[x,y], labelSize?,  // центр подписи
  border?: "tribe"|"kingdom",  // стиль границы
  note?, cities?:[ids],        // для карточки/связок
}]
```
Движок: `<path>` заливка (tint из палитры, opacity ~.42) + `<path>` граница
(non-scaling, dash по стилю) + текст-подпись + опц. номерной бейдж-кружок.
Клик → инфо-карточка (как у глифов). LOD: заливка чуть гаснет на глубоком зуме,
чтобы не давить города/подписи. Палитра `REGION_TINTS` — 12 различимых
пастельных тонов (по эталону): judah=терракота, benjamin=золото, ephraim=
зелёный, manasseh=бирюза, dan=лосось, simeon=фиолет, gad=оранж, reuben=синий,
asher=олива, naphtali=жёлтый, zebulun=пурпур, issachar=крем; kingdoms:
israel=синий, judah=золото, other=серый.

### E2. Эпохи/таймлайн — `route.eras[]` + переключатель
Данные могут зависеть от эпохи: у `regions`/`places`/`overlays` опц. поле
`era: "divided"`. Движок строит **вкладки эпох** (переиспользуя механику
stage-strip) и по клику показывает только элементы активной эпохи (CSS-класс
`era--<id>` на корне + `data-era`). Дефолт — первая эпоха.
```
eras: [{id:"united", t:"Объединённая монархия", years:"~1050–930 до н.э."}, ...]
```
Питает: melachim (Царства), новую «Израиль сквозь века».

### E3. Слои-темы — `route.themes[]` (тумблеры)
Панель тумблеров (эталон: Пророки/Торговые пути/Военные/Границы…). Каждый
тумблер показывает/прячет группу по классу. Переиспользует существующий слой
кнопок читалки. Данные — список `{id,label,icon?,default}`.

### E4. Обогащение панелей
- **Легенда-список территорий** (левый блок): цвет+номер+имя из `regions`.
- **Нижняя лента карточек** — уже есть stage-strip; обобщить, чтобы принимала
  карточки колен (`regions`), не только этапы.
- Инфо-карточка территории (Территория/Ключевые города/Наследие/цитата).

## 4. Карты-деливеры (на этих примитивах)

### M1. shvatim → «Наследие колен» (12 уделов) ⭐ ПРИОРИТЕТ
- Данные: 12 полигонов уделов (+ Манассия З/В) по Иис.Нав.13–19, калибровка
  levant (lonToX=623+(L−35.22)·100, latToY=800−(B−31.78)·120). Левий — без
  удела (сноска). Города внутри уделов (уже есть точки).
- Слои-темы: Границы колен, Города-убежища, Левитские города, Важные города.
- Легенда 12 цветов + карточки колен внизу (наследие + ссылка Нав).
- Гейты + зонд: полигоны не перехлёстывают море, подписи уделов без наездов.

### M2. nachalo → богаче (Книга Народов)
- Зоны Иафет/Сим/Хам как мягкие заливки-регионы (E1) вместо только стрелок.
- Имена народов внутри зон: Иафет (Гомер, Магог, Мадай, Иаван, Фувал…),
  Хам (Хуш, Мицраим, Фут, Ханаан), Сим (Елам, Ашшур, Арфаксад, Луд, Арам).
- Больше визуальной опоры: разлив вод потопа/ковчег крупнее, картуш-сноска.

### M3. Новая карта «Израиль сквозь века» (таймлайн) — E1+E2
- Эпохи: Салим/Мелхиседек → Судьи → Объединённое царство (Саул/Давид/Соломон)
  → Разделённое (Израиль/Иудея) → Ассирия → Вавилон → Персия/возврат →
  Хасмонеи → Ирод. (Расширение к современности — обсудить отдельно: чувствит.)
- Территории-заливки по эпохам (E1 с `era`), династии-сайднот.

### M4. melachim → «Царства» с границами (E1+E2)
- Израиль(син.)/Иудея(зол.)/соседи(сер.) как территории; вкладки эпох.

## 5. Порядок исполнения (выбран)

1. **E1 (территории)** — фундамент. Без него M1/M2/M3/M4 невозможны.
2. **M1 (12 колен уделами)** — флагман, максимальный видимый эффект, проверка
   E1 на реальной карте.
3. **E3 + E4** (слои-темы, легенда-список, карточки) — довести M1 до эталона.
4. **M2 (nachalo богаче)** — быстрый выигрыш на E1.
5. **E2 (эпохи)** → **M4 (melachim царства)** → **M3 (новая таймлайн-карта)**.
6. Сквозная полировка: линии-пути, микро-наезды, цитата Быт 15:18, кросс-карта.

## 6. Данные, которые нужны

- Полигоны 12 уделов (draft по стандартной картографии Нав.13–19 → калибровка
  в юниты). Точность — атласная (±, узнаваемые формы), выверка по городам-якорям
  (Иерусалим, Хеврон, Сихем, Мегиддо, Хацор, Беэр-Шева, Рамоф-Галаадский…).
- Границы царств Израиль/Иудея (разделённое царство ~930–722).
- Книга Народов: имена и грубые ареалы (Быт 10) — есть ресёрч-заготовка.

## 7. Инварианты (не ломать)

- 8× зум и data-binding сохраняются; всё через `<symbol>`/классы/non-scaling.
- Территории — ПОД городами/маршрутами/подписями по z-порядку.
- Каждый примитив — опционален: карта без `regions`/`eras`/`themes` рендерится
  как раньше (обратная совместимость всех 11 листов).
