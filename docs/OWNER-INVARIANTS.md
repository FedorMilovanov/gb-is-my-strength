## Контент и правда

1. **Никакой правдоподобной лжи.** Квизы, «Коротко», числовые заявления («N позиций»),
   цитаты и имена — только из фактического текста статьи или заявленного источника.
   Паритет Astro↔legacy НЕ доказывает правду (класс ошибок доказан историей:
   инверсия тезиса герменевтики, выдуманные факты в квизе Гилла, устаревший квиз
   Антисоветова, «5 позиций» при четырёх).
2. **Свежесть не подделывается.** CSS/JS/технические коммиты не должны менять
   редакционные даты статей (`article:modified_time`, `dateModified`, sitemap lastmod).
   `dateModified` — только значимое редакционное обновление.
3. **Цитаты Писания — дословно по заявленному изданию** (Синодальный). Пересказ/
   модернизация под видом дословной цитаты запрещены. Источник — конкретное издание,
   не «выверено в статье».
4. **Авторство:** «Автор-редактор» (типы A/B) / «Редактор» (тип C). Никогда «Автор:
   Фёдор Милованов». AI-disclosure не восстанавливать.

## UI / владельческие зоны

5. **PremiumControls / Floating Cluster / Gill — owner-sensitive, in-flight.**
   Не доделано; freeze-правила AGENTS §3.10. Визуальные изменения — только по явному
   запросу владельца. Исторический pre-v16 submenu-контракт и rounded frame охраняются
   аудитами (`gill:pre-v16-submenu:audit` — если падает, это дефект, не шум).
6. **Глоссарий и Библия-тултипы — активный трек владельца.** Данные
   (`data/glossary.json`, `data/verses.json`, `data/bible/`) обновляет владелец;
   агенты не делают массовых правок данных. HARD LOCK: `.summary-card` — только
   plain-text (AGENTS §9.21).
7. **Визуальный контракт не ухудшается.** Скриншот-паритет и owner-ui-guard —
   обязательные; «выглядит нормально» — не доказательство.

## Процесс / доверие

8. **Production-like green ≠ финальный green.** Полный релизный контракт должен
   выполняться ДО merge в main; «merge-first, repair-later» (PR#45→#48) — антипаттерн.
9. **Зелёный шаг workflow ≠ доказательство** (IndexNow глушится `|| true`;
   `[skip ci]` bot-HEAD не проверен сам по себе). Закрытия — только с fixture + fix +
   гейты + immutable SHA.
10. **Каноническая правда аудита — AuditRepo** (`MASTER_BUG_MATRIX.md` +
    `SUPER_AUDIT_2026-07-06_14a49be8.md`), не чат-контекст и не старые отчёты.
