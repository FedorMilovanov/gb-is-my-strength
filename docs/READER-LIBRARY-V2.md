# Единая библиотека читателя — контракт v2

**Owner:** `js/highlights.js` (единое хранилище, выбор текста, подключение панели), `js/reader-library-presenter.js` (ленивая DOM-презентация и экспорт, без собственного хранилища), `css/highlights-runtime.css` (визуальная система). Отображение загружается только при открытии библиотеки, при этом asset версионируется и прекэшируется для офлайна.

## Намерение владельца

- Сохранение **всей статьи** остаётся в прежнем `SaveButton` и `GBFavoriteStore`, в прежнем месте UI. Библиотека не дублирует запись «избранного».
- **Одна** кнопка «Моя библиотека» в видимом нижнем баре читателя; на широком экране, где мобильная панель скрыта, — компактная плавающая кнопка. При смене ширины без перезагрузки кнопка переходит между позициями и не пропадает. Она открывает статьи, цитаты и личные заметки.
- Длинные цитаты и заметки читаются в свёрнутом состоянии (4 строки) и разворачиваются по нажатию; старый полный текст не сокращается при хранении.
- Лёгкая анимация открытия и нажатия; `prefers-reduced-motion` отключает движение.
- Поиск, категории и фильтр по исходной статье работают совместно; большой список выводится порциями.

## Данные и миграция

| Вид | Ключ | Единственный владелец записи | Ограничение |
|---|---|---|---|
| Цитаты | `gb-highlights-v1` | `GBHighlights` | 200 (старый лимит) |
| Личные заметки | `gb-reader-notes-v1` | `GBHighlights` | 500 |
| Избранные статьи | `gb-favorites` | `GBFavoriteStore` | 50 (существующий лимит) |

Старые цитаты сохраняют ID, текст, ссылку `#:~:text=`, дату и название статьи. Дубликаты цитат нормализуются по пути и тексту, одинаковые цитаты из разных статей остаются отдельными. Статьи читаются через `GBFavoriteStore.list()`; fallback-путь только читает старое хранилище, без новых writer-ов.

Заметки включают собственный текст, источник, дату и (при необходимости) текст связанной цитаты. Удаление обратимо через краткую команду «Отменить». Записи не удаляются автоматически при исчерпании квоты; отказ хранилища показывается человеку.

Экспорт Markdown включает все категории. Сохранённые тексты доступны **в пределах одного браузера/профиля на том же origin**; межустройственная синхронизация здесь не заявлена.

## Визуальная и техническая ответственность

- Кнопка библиотеки имеет отдельный SVG «раскрытая книга», не подменяющий прежнюю SVG-закладку.
- Система не заменяет панель настроек чтения, Play/speedrail, сноски, модальные окна Писания и глоссария.
- Существующий `#selection-share-popup` расширяется двумя действиями: сохранить цитату и добавить связанную заметку. Дублировать выделяющее меню запрещено.
- Один контейнер `#gb-hl-backdrop`, один набор listeners, фокус возвращается к открывавшему контролу; в закрытом состоянии `inert`.
- Навигация по сохранённому фрагменту остаётся ссылкой на исходный документ; экран библиотеки не создает ложных «постоянных» серверных ссылок.
