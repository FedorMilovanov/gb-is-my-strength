# ADR: Архитектура карт — «все флагман», а не «1 флагман + костыли»

**Статус:** Рекомендация (требует решения владельца по объёму) · **Дата:** 2026-06-18
**Контекст:** §12.5, ADR-ABRAHAM-CONSOLIDATION. Сейчас Авраам = уникальный рендер (2404 строки), 9 карт = MapEngine `createMap()` (функционально, но «полуфлагман»).

---

## Постановка проблемы владельца
> «Не 1 флагман, а другие полуфлагман костыли. Чтобы все были на максимально топовом уровне.
> Улучшать движок стилями и глубиной прорисовки и брать оттуда [из Авраама]? Но с уникальными особенностями для каждой карты.»

## Ответ: **ДA — поднимаем движок до уровня Авраама (deep engine), но КАЖДАЯ карта получает свой уникальный «character».**

Это НЕ «перенос рендерера Авраама» (отвергнуто в ADR-ABRAHAM). Это **противоположное направление**:
извлечь из Авраама generic-«премиум»-слой в движок, оставив уникальное — уникальным.

### Ключевое различение: 3 слоя фич Авраама

| Слой | Что это | Примеры | Куда |
|---|---|---|---|
| **A. Generic premium** | Visual polish, полезный ВСЕМ картам | SVG glow-фильтры, ripple при клике, spring-вход маркеров, премиум-типографика, кинематографическое интро, ambient-свечение, параллакс-компас, стрелки на путях, label-подложки | → **в движок** (уже идёт: v0.7→v0.44 извлёк 60 фич) |
| **B. Per-map content** | Контент-специфичные данные | Караван Авраама, морские пути Павла, переправа Исхода, 7 светильников Откровения | → в **route.json** как опциональные data-driven overlays |
| **C. Abraham-signature** | Идосинкразичные декорации | Ночные звёзды, GSAP DrawSVG торговых путей, ambient-аккорды (8 тональностей), fog-of-war, картуш-легенда | → **остаются уникальными** (опциональные engine `opts` для желающих) |

**Вывод:** ~80% «флагманности» Авраама — это слой A, который УЖЕ извлекается в движок (v0.44, 60 фич). Осталось ~20% — это слои B/C. Стратегия: довести движок до 90%+ premium-покрытия (слой A), и дать каждой карте свой character через route.json + opts.

## План: «все флагман» за 3 волны

### Волна 1 — Deep Engine (поднять базовый уровень, БЕЗ touching Abraham)
Доработать MapEngine до premium-паритета со слоем A Авраама. Цель: движковые карты выглядят «дорого» по умолчанию.
- [ ] Премиум SVG-фильтры: goldGlow/neonGlow/waterRipple/terrainTextur (как у Авраама)
- [ ] Кинематографическое интро-экран (stars/gradient + статистика + кнопка «начать кинотур»)
- [ ] Spring-анимации входа маркеров (staggered), ripple при клике, markerBounceActive
- [ ] Параллакс-компас + меридиан-сетка + координатные подписи
- [ ] Ambient-свечение/«дыхание» маршрутов (routeIdle)
- [ ] Картуш-легенда + декоративные углы рамки (опционально через opts.ornate)
- [ ] prefers-reduced-motion guards (✅ уже добавлено)
**Верификация:** golden-screenshot-сравнение движковой карты vs Авраам — «дорого» должно совпадать.

### Волна 2 — Per-map character (каждая карта уникальна через data)
Каждая карта получает **сигнатурную фичу** через route.json overlay / engine opts. Не копипаст — переосмысление под контент.
| Карта | Сигнатура (предложение) |
|---|---|
| avraam | (эталон — не трогать) караван + звёзды + аккорды |
| ishod | Расступающееся море (animated water-split на этапе переправы), огненный столп ночью |
| pavel | Морские пути (кораблик-анимация по волнам), шторм (Деян 27) |
| shoftim | Циклы отступничества (генеративный timeline-волновой паттерн: грех→гонение→судья→покой) |
| melachim | Разделённое царство (визуальное расщепление Израиль/Иудея, цветовой gradient власти) |
| shvatim | Распределение уделов (территориальная заливка-heatmap 12 колён) |
| yeshua | Три года служения (animated timeline-нить: события «зажигаются» по хронологии) |
| maccabim | Ханука-свет (8 свечей, зажигающиеся по дням), эллинизация vs вера |
| early-church | Распространение Евангелия (расходящиеся волны из Иерусалима, Деян 1:8) |

### Волна 3 — Future maps (межзаветное, империи Даниила, диспенсационализм)
Новые карты строятся НА готовом deep engine + получают свою сигнатуру:
- **Межзаветный период** (уже maccabim) — расширить: Птолемеи/Селевкиды/Хасмонеи/Ироды как наслаивающиеся эпохи
- **Империи Даниила** (золотая голова → серебро → медь → железо → глина) — статуя + 4 зверя + сопоставление с реальными империями (Вавилон/Мидо-Персия/Греция/Рим). UNIQUE: синхронный timeline «пророчество ↔ история»
- **Завоевания Македонского** — расширение карты империй реальными маршрутами Александра
- **Диспенсационализм** — отдельная infographic-схема (не карта): эпохи домостроительства, пересмотренный взгляд

## Принцип «не ломать» (преемственность с ADR-ABRAHAM)
1. Волна 1 = ТОЛЬКО добавление в движок. `avraam:audit 24/24` должен оставаться зелёным. Авраам НЕ трогаем.
2. Каждая сигнатура Волны 2 — опциональна (`opts.signature` или route.json overlay), по умолчанию off → обратная совместимость.
3. Новая карта-сигнатура проходит: golden-screenshot + visual-QA (Playwright) перед commit.
4. Когда движок достигнет 90%+ premium-покрытия (Волна 1 готова) — ТОЛЬКО тогда можно обсуждать, нужен ли Аврааму свой рендер (см. ADR-ABRAHAM безопасный путь).

## Технически: как «signal feature» не превращается в копипасту
Шаблон новой сигнатуры (паттерн data-driven overlay):
```js
// route.json
{ "signature": { "type": "water-split", "trigger": "stage:crossing-red-sea", "opts": {...} } }
// engine: if route.signature → рендерит overlay, не трогая ядро
```
Каждая сигнатура = изолированный overlay-модуль (~50–150 строк), живёт в движке как опциональный плагин. НЕ дублирует рендер-ядро.

## Рекомендация по порядку
1. **Сейчас:** контент карт закрыт (arch/dispute ✅). Движок уже v0.44 (60 фич).
2. **Следующий большой шаг:** Волна 1 (deep engine premium-слой) — ~5–10 коммитов, каждый = одна premium-фича + visual-QA.
3. **Потом:** Волна 2 по одной карте (начать с ishod/pavel — простые, потом сигнатурные).
4. **Future:** новые карты (Даниил, Александр) сразу на deep engine + своя сигнатура.

Это превращает «1 флагман + костыли» в «10 флагманов, каждый со своим характером».
