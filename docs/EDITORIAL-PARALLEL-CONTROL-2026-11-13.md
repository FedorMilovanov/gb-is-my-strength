## Проверки PR #2302 и порядок выпуска

На проверенном HEAD PR оставался draft и имел несколько красных GitHub checks. GitHub API показал, в частности, сбой шагов проверки исходного индекса, canonical discovery, dependency security и lane collisions. Логи шагов через Actions в этой среде получить не удалось; причины остальных сбоев не установлены. Наш независимый `--check` подтвердил устаревший индекс, но не доказывает причины каждого красного job. Не считать PR готовым к выпуску только по позитивным браузерным проверкам или его описанию.

Рекомендуемый порядок: согласовать владельца текста и локальных ссылок A–D; свести содержательные версии вручную, включая safety-оговорки и исторические границы; разрешить ID реестра Лоусона; пересчитать минуты и заново сгенерировать индекс; затем последовательно выполнить source/strict/build/dist-контракты и реальные браузерные проверки. Не копировать производный индекс с одной стороны и не считать старый PASS гарантией результатов после объединения.
