# GBS Design References — REPO LIGHT

Этот архив собран автоматически из удачных одиночных референсов, созданных для проекта `gb-is-my-strength`.

## Важно

- Это **визуальные UI/UX-референсы**, а не источники географии, богословских формулировок или библейских данных.
- Не копировать текст с изображений без проверки.
- География, маршруты, родословия, подписи и источники должны идти из `route.json`, валидаторов, проверенных источников и редакционного аудита.
- Ошибочные коллажи/композитные борды исключены из архива.
- Изображения сжаты в `.webp`, чтобы не раздувать репозиторий и ускорить аудит.

## Рекомендация по репозиторию

В репо держать только лёгкий curated-набор:
`docs/design-references/...`

Полный архив и сырые PNG лучше хранить вне Git, например на Google Drive.

## Содержимое

- Количество изображений: 43
- Тип набора: curated для репозитория
- Формат изображений: WebP
- Есть manifest: `reference_manifest.csv`

## Папки

- `01_genealogy_references` — родословие, zoom, полная генеалогическая база, Матфей/Лука.
- `02_maps_desktop_core` — основные desktop-карты и атласные виды.
- `03_maps_mobile_tablet` — mobile/tablet/narrow layout.
- `04_maps_states_admin_editor` — состояния, аудит, редакторы, экспорт, ошибки.
- `05_site_map_references` — карта сайта / network graph.
- `00_docs` — MD-исследования и ТЗ.

## Для агента

Использовать эти изображения как ориентир по:
- композиции;
- цветам;
- состояниям интерфейса;
- desktop/mobile UX;
- структуре панелей;
- уровню визуального качества.

Не использовать как:
- готовые ассеты сайта;
- точные карты;
- источник координат;
- источник фактических подписей.
