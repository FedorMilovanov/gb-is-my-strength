# Agent Notes — Design References

Эта папка предназначена только для дизайн-референсов.

## Не делать

- Не подключать эти изображения в публичную сборку сайта.
- Не использовать их как картографический или богословский источник.
- Не переносить DALL·E-текст в интерфейс без проверки.
- Не добавлять сырые PNG и ZIP-архивы в репозиторий.

## Делать

- Смотреть на композицию, UX-состояния, панели, mobile/desktop-логику.
- Реализовывать карты data-driven через MapEngine v2.
- Использовать `route.json` и валидаторы как источник истины.
- При добавлении новых референсов сжимать в WebP, max long edge ~1500–1800 px.
