## 2. Детальный аудит по ключевым критериям

### 2.1. Нативные якоря, Tab, Back/Forward и навигация источников
- **Якоря и секции:** Все 11 модульных разделов статьи (`#overview`, `#timeline`, `#finance`, `#governance`, `#buice`, `#buck`, `#wind-down`, `#unknowns`, `#documents`, `#bibliography`, `#corrections`) имеют явный атрибут `tabindex="-1"`. Это гарантирует, что браузерный метод `target.focus({ preventScroll: true })` корректно переносит фокус ввода на заголовок секции после клика в оглавлении на мобильных устройствах.
- **Двунаправленная связь «цитата ↔ источник» (`JournalSourceReturn`):**
  - При клике на цитату (`a[data-journal-citation][id]`) динамически обновляется обратная ссылка в соответствующем элементе `.bibliography-item`: атрибут `href` переключается на точный `#cite-...`, а метка `aria-label` — на `«К месту чтения: ...»`.
  - При внешнем переходе или перезагрузке страницы (`reload`) ссылка честно сохраняет SSR fallback на `#documents` (для досье) и `#g3-history` (для рукописи).
  - Модификаторы клика (Ctrl/Cmd/Shift/Alt) и средняя кнопка мыши корректно игнорируются, не вызывая побочных мутаций состояния.
  - Нажатия клавиш Back/Forward в браузере сохраняют полную историю переходов без разрыва цепочки.
- **Клавиатурная доступность:** При переходе по ссылке «К месту чтения» фокус восстанавливается в контексте основного текста статьи.

### 2.2. Липкий рельс и управление фокусом (Sticky Rail & Low Viewports)
- **Десктоп ($\ge 1024$ px):** 
  - Рельс `.je-editorial-rail` использует `max-height: calc(100svh - 2 * var(--je-rail-clearance) - env(safe-area-inset-bottom, 0px))` с `overflow-y: auto`, где клиренс точно согласован с системным `72px` scroll-padding документа.
  - В невысоких окнах ($390–600$ px) колесо мыши над рельсом прокручивает меню, не вызывая дрейфа основного текста статьи.
  - Внешний контур фокуса (7px) защищён от обрезания отрицательным внешним и положительным внутренним отступом (`padding: 8px; margin-inline: -8px`).
- **Мобильные ($\le 1023$ px):**
  - Оглавление складывается в компактный раскрывающийся `<details class="je-contents">`.
  - Внутренний контейнер `nav` ограничен `max-height: 50svh; overscroll-behavior: contain`.
  - В коммитах `e470715` $\to$ `ad0bfa4` $\to$ `dedbcdaba` Агент 8 безупречно решил проблему видимости контура фокуса: для `summary` задан `outline-offset: -3px` (полностью внутри кликабельной области), а для ссылок внутри `nav` предусмотрен запас `scroll-padding-block: 8px`.

### 2.3. Геометрия верстки и отсутствие переполнения (320–1440 px)
- **320 px (минимальный порог):** В шапке логотип скрывается только при $< 360$ px, заголовок плавно масштабируется (`clamp(33px, 9.3vw, 46px)`), таймлайн перестраивается в одну колонку (`grid-template-columns: 1fr`). Горизонтальный скролл отсутствует (`scrollWidth === clientWidth`).
- **390–768 px (смартфоны и планшеты):** Рельс нативно переносится перед контентом статьи (`grid-row: 1`), навигация мастхеда распределяется по сетке `repeat(2, minmax(0, 1fr))`, исключая обрезание ссылок.
- **1024–1440 px (десктоп):** Сетка `journal-feature-grid` задаёт комфортную редакционную меру чтения $740$ px, оставляя $250$ px под боковой навигационный рельс.

### 2.4. Печатная вёрстка (Print Styles & PDF)
- **Скрытие экранных контролов:** Мастхед, боковой рельс, плавающие кнопки и обратные ссылки цитат скрываются (`display: none`).
- **Разбивка на полосы:**
  - В отличие от ранних подходов с тотальным `.module { break-inside: avoid; }` (приводившим к 60% пустых полос), у Агента 8 модули свободно перетекают между страницами.
  - Защита от разрыва (`break-inside: avoid`) установлена строго на атомарные смысловые блоки: `.bibliography-item`, `.je-data-figure`, `.je-next-story`, `.dossier-footer`.
  - Свойство `break-after: avoid` на заголовках (`h2, h3, h4, .module-label, .eyebrow, .je-history-heading`) надёжно защищает от «висячих строк».
- **Нумерация библиографии:** Использование псевдоэлемента `::before` с абсолютным позиционированием внутри `padding-left: 39px` полностью предотвращает выход двузначных номеров за пределы листа бумаги (проблема, обнаруженная в #2343 с нативным `<ol>`).

## 3. Точечные селективные рекомендации для интеграции в PR #2338

При формировании объединённого пакета для `lane/journal-editorial-premium-20261118` рекомендуются следующие минимальные дополнения:

### Рекомендация 1: Поддержка Windows High Contrast (`forced-colors: active`)
В текущей реализации `JournalMasthead.astro` ссылки навигации используют прозрачную нижнюю границу (`border-bottom: 2px solid transparent`). В режиме высокой контрастности Windows браузер заменяет все прозрачные границы на видимый системный цвет, из-за чего все 4 ссылки выглядят одинаково активными.
*Решение (из наработок Агента 7 / #2341):*
Добавить в блок стилей `JournalMasthead.astro`:
```css
@media (forced-colors: active) {
  .je-masthead__nav a { border-bottom-color: Canvas; }
  .je-masthead__nav a[aria-current] { border-bottom-color: Highlight; }
}
```
И в `journalEditorial.css` для бейджа:
```css
@media (forced-colors: active) {
  .journal-edition .journal-story-tag { border: 1px solid CanvasText; }
}
```

### Рекомендация 2: Route-owned SEO Metadata (#2345)
Перенести изолированное исправление Агента 6 из PR #2345: строгую передачу дат `publishedAt` и `modifiedAt` от страниц в `JournalDocumentHead.astro`, а также ограничение `og:type="article"` только на статьях досье.
