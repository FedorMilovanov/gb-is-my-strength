1. **В границах семантики и клавиатурной доступности:**  
   Реализация нативного меню `<details>/<summary>` в `JournalMasthead.astro` оценивается как **PASS (в узком скоупе Semantics/Keyboard)**:
   - Полное соблюдение W3C First Rule of ARIA;
   - Корректная табуляция (`Tab` / `Shift+Tab`) без ловушек фокуса;
   - Отсутствие зависимости от клиентского JavaScript;
   - Восстановление точек входа в 5 разделов каталога на мобильных экранах без горизонтального переполнения (`overflow: 0`).
2. **Вне скоупа (COLD_CLS_NOT_COVERED / NO BROWSER EVIDENCE CLAIM):**
   - Данное ревью **не измеряло и не покрывало метрики сдвига макета (CLS)** при холодной загрузке и свопе веб-шрифтов.

## 2. Результаты проверки по ключевым UX/A11y плоскостям

### 2.1. Семантика и отсутствие ложных ARIA-ролей (W3C First Rule of ARIA)
- Использован нативный элемент раскрытия `<details class="je-masthead__site-sections" data-journal-site-sections>` с дочерним `<summary>Разделы сайта ...</summary>`.
- **Zero false ARIA:** Разработчик отказался от искусственных ролей `role="menu"` / `role="dialog"` / `aria-haspopup="menu"`, которые требовали бы сложной скриптовой обработки фокуса, стрелочной навигации и ручного управления `aria-expanded`.
- Браузер и скринридеры нативно озвучивают состояние (раскрыто / свёрнуто) через встроенную семантику элемента `<details>`.

### 2.2. Клавиатурная навигация и отсутствие Focus Trap
- **Активация:** Элемент `<summary>` нативно фокусируется по клавише `Tab` и открывается/закрывается по нажатию `Enter` или `Space`.
- **Последовательность табуляции (Tab Order):** При открытом `<details>` нажатие `Tab` последовательно переводит фокус по всем 5 ссылкам:
  1. `/#publikacii` (Публикации)
  2. `/#razbor` (Разбор заблуждений)
  3. `/biografii/` (Биографии)
  4. `/app/` (Приложение)
  5. `/about/` (Об издании)
- **Отсутствие ловушки фокуса (No Keyboard Trap):** После 5-й ссылки (`/about/`) следующее нажатие `Tab` штатно переводит фокус на следующий элемент страницы (кнопку поиска / переключатель темы / контент).
- **Реверсивный ход:** Нажатие `Shift+Tab` безошибочно возвращает фокус назад вплоть до `<summary>`.
- **Фокусные кольца (Focus Visible):** Правило `.je-masthead :is(a, button, summary):focus-visible { outline: 2px solid #eacb85; outline-offset: 3px; }` гарантирует четкое визуальное выделение активного элемента с контрастом $\ge 3:1$, соблюдая WCAG 2.4.7 AA и WCAG 2.4.13 AAA.

### 2.3. Доступность в среде без JavaScript (no-JS)
- Раскрытие панели, кликабельность ссылок и навигация полностью функциональны при отключенном JavaScript.
- Все 5 ссылок указывают на реальные, существующие в production-дистрибутиве адреса:
  - `/#publikacii` — точный якорь на главной;
  - `/#razbor` — точный якорь на главной;
  - `/biografii/` — полноценный раздел биографий;
  - `/app/` — страница приложения PWA;
  - `/about/` — страница «Об издании».

### 2.4. Мобильная геометрия и защита от переполнения (320 px / 390 px)
- **Ширина панели:** Задано `width: min(280px, calc(100vw - 40px));`.
  - При ширине экрана 320 px доступная ширина с учетом боковых отступов мастхеда (20 px слева + 20 px справа) составляет ровно 280 px ($20 + 280 + 20 = 320$ px).
  - Панель позиционируется `right: 0` внутри второй колонки мобильной сетки и идеально вписывается в экран с отступами по 20 px с обеих сторон.
  - **Горизонтальный скролл полностью отсутствует (`overflow: 0`).**
- **Ограничение по высоте:** Свойство `max-height: min(26rem, max(88px, calc(100svh - 165px))); overflow-y: auto;` гарантирует, что панель не выйдет за пределы видимой области даже на смартфонах в ландшафтной ориентации (short viewport).

### 2.5. Площадь нажатия (Target Size)
- Элементы списка `li a` имеют явный `min-height: 44px; padding: 8px 10px; display: flex; align-items: center;`.
- Это на 100% удовлетворяет стандарту **WCAG 2.2 AA (Критерий 2.5.8: минимум $24\times24$ px)** и рекомендациям **Apple HIG / Google Material ($44\times44$ px)**.

### 2.6. Кросс-роутинг: поведение на `/articles/`, `/journal/`, `/journal/dossiers/g3/`
- На всех трех маршрутах используется единый шелл `JournalMasthead.astro`.
- Активный раздел безошибочно подсвечивается через `aria-current="page"` (или `"true"` для досье) и золотую подчеркивающую линию `border-color: #d6ad5d; color: #fff;`.
- В режиме высокой контрастности Windows High Contrast (`forced-colors: active`) текущий раздел выделяется системным цветом `Highlight`.
- В режиме печати (`@media print`) мастхед корректно скрыт (`display: none;`).

## 3. Корректировка рекомендаций (Corrigendum по директиве Координатора)

В соответствии с замечаниями Владельца репозитория ([PR #2341 / коммент 7022596403](https://github.com/FedorMilovanov/gb-is-my-strength/pull/2341#issuecomment-7022596403)):

1. **ОТЗЫВ рекомендации по JS-автозакрытию меню:**
   - Первоначальное предложение добавить `addEventListener('click')` для ссылок `/#publikacii` и `/#razbor` **отозвано**.
   - **Причина:** Ссылки `/#publikacii` и `/#razbor` ведут на другой документ (корень сайта `/`), где компонент `JournalMasthead` вообще не монтируется. При переходе происходит выгрузка текущей страницы и загрузка главной; меню размонтируется вместе со страницей. Добавление скриптового обработчика для закрытия перед навигацией является избыточным и нарушает принцип zero-JS навигации.
2. **СНЯТИЕ замечания по `aria-current` для `/about/`:**
   - Компонент `JournalMasthead` обслуживает исключительно журнал и статьи (`/articles/`, `/journal/`, `/journal/dossiers/g3/`) и не монтируется на странице `/about/`.
   - Требование подсветки активного состояния для `/about/` внутри выпадающего списка `JournalMasthead` признано **out of scope**.
3. **Мобильная высота ячейки на 320 px:**
   - Значение `min-height: 39px` удовлетворяет критерию WCAG 2.2 AA 2.5.8 (минимум 24 px) и остаётся на усмотрение visual owner (Агента 8).
