# 25. 3D-карта русского баптизма: безопасный план обновления истоков по новым первоисточникам

Дата: 2026-06-18  
Статус: план data-only обновления; **не выполнять визуальный ребилд iframe без отдельного QA**.

---

## 1. Почему нужен отдельный план

Мы уже нашли больше источников, чем текущая 3D-карта способна честно показать без перегруза. Если просто накидать новых узлов, карта станет красивой, но начнёт обманывать: штунда, баптистская форма, немецкие колонии, меннонитское братство, Петербург, Ново-Васильевка — всё сольётся в один блестящий ком.

Поэтому правило такое: **сначала данные и логика, потом визуал**.

---

## 2. Исправления, которые уже понятны

### 2.1. Южная штунда

Текущая карта говорит в целом верно, но слишком плоско: «Южная Украина / Цимбал / Вилер». Теперь надо показывать слойнее:

- local reading circles: Карловка, Любомирка, Основа;
- Mennonite Brethren network: Einlage, Molotschna, Kuban;
- German Baptist channel: Oncken, Pritzkau, Alt-Danzig;
- Slavic chain: Цимбал → Рябошапка → Ратушный;
- order/confession: Вилер, Правила Русского Братства, миссионерский комитет.

### 2.2. 1884

Текущая карта должна иметь два отдельных события:

1. **Петербург 1–6 апреля 1884** — широкое евангельское совещание, граница по вопросу крещения, полицейское вмешательство.
2. **Ново-Васильевка 30 апреля 1884** — баптистская конференция/съезд южных общин, 33 депутата, вопрос Вечери, братский порядок.

Не один узел. Не один label. Не один route step.

### 2.3. Онкен

В старом timeline был рискованный смысл: «в 1884 попытка объединения с Ворониным и Онкеном». Это неправильно как формулировка. Онкен — ключ к немецко-баптистскому каналу 1860-х/1870-х, но не участник Петербургской конференции 1884.

## 4. Предлагаемый data-patch без визуального риска

### Этап 1 — только текстовые уточнения существующих узлов

Не добавлять новых планет. Обновить только tooltip/dossier текст:

- `ukr` — описать как «южная сеть», а не один штундистский очаг.
- `tsymbal` — Цимбал как вход в баптистскую форму, но с предысторией Карловки.
- `weiler` — Вилер как bridge to brotherhood order, не просто «немецкий баптистский руководитель».
- `vsb` — Ново-Васильевка как conference/order, не просто «вхождение в союз».
- `spb` — Петербург 1884 как broad evangelical meeting, не Baptist congress.

### Этап 2 — route/story layer без новых узлов

Добавить story mode / route preset:

- `route-southern-network-1869-1870`
- nodes: `ukr`, `tsymbal`, `weiler`, `vsb`, возможно `mazaev` как поздний continuation.
- captions explain: Karlovka/Lubomirka/Alt-Danzig are currently represented inside the southern node, not separate places.

### Этап 3 — новые map markers, но не новые graph nodes

Добавить city/area markers only:

- Karlovka / Sukhakleya area;
- Lubomirka;
- Osnova;
- Alt-Danzig;
- Annenthal / Steinberg / Odessa.

Они должны быть mapSelection markers, not full orbit nodes. Это даст географию без перегруза 3D-графа.

### Этап 4 — новые graph nodes только после QA

Только если визуал выдержит:

- `karlovka-reading-circle`
- `alt-danzig-baptism-order`
- `ratushny-osnova`
- `rules-ratushny-1871`

Но это уже отдельный visual/data design PR.

## 5. QA перед любым rebuild iframe

Минимум:

```bash
npm run konfessii:audit
npm run validate:all
node scripts/audit-pro.js
npm run smoke:konfessii
```

Плюс ручная проверка:

- desktop 1366×900;
- mobile 390×844;
- route/timeline клики;
- «Маршруты» не перекрывают dossier;
- wheel/drag не ломают iframe;
- source badges видны, но не превращают карту в таблицу.

---

## 6. Главное наставление для следующего агента

Не пытайся «сразу красиво добавить всё найденное». История стала глубже, но карта должна оставаться читаемой. Лучше один точный поясняющий слой, чем десять новых светящихся узлов, которые смешают штунду, баптизм, меннонитов, Пашкова и съезды в одну кашу.
