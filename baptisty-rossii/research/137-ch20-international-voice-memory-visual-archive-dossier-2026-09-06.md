## 2. AAPB metadata conflict — do not copy the catalog description blindly

AAPB metadata description says Vins `arrived in the United States in April, 1978`.

That is wrong.

Controls:
- official White House exchange statement = **27 Apr 1979**;
- program broadcast = **9 Jul 1979**;
- the program transcript itself clearly places his release/arrival only weeks earlier in 1979.

Therefore:
- `April 1978` = **CATALOG METADATA ERROR**;
- canonical year = **1979**.

This is a model example for Chapter 20's memory/archive method:
> a respected modern archive can still carry a simple metadata error that must be reconciled against primary chronology.

Production rule:
- never use catalog prose as the sole date source;
- cite the audiovisual object and event chronology separately.
