## Кандидаты для поиска

### Ночь на Куре

- исторический Тифлис / река Кура;
- портреты или изображения, связанные с Ворониным, Кальвейтом, Деляковым;
- сканы источников по письму Воронина 1889 года.

### Южная штунда

- южнорусские немецкие колонии;
- портреты / упоминания Унгера, Цимбала, Рябошапки, Ратушного, Прицкау;
- сканы Дородницына и Рождественского.

### Петербургская линия

- Пашков;
- Проханов;
- Каргель;
- Петербург XIX века;
- страницы из евангельских изданий.

### Советская ночь / Инициативная группа / Подпольная печать

- страницы советских нормативных актов;
- молитвенные дома / закрытия / репрессии, если права ясны;
- обложки «Вестника спасения», «Вестника истины», материалов Совета родственников;
- фотографии печатных машин / самиздата только при ясной лицензии.
