# map-data — черновые данные для будущего SVG/3D-атласа ЕХБ

Дата старта: 2026-06-14

Эта папка — не публичная база и не готовая карта. Это проверочный черновик для будущего 2D/SVG-атласа церквей, пасторов, закрытий и гонений.

## Файлы

- `church-points-draft.csv` — первые исторические и современные точки: общины, центры, регионы, типографии, места гонений.
- `closure-events-draft.csv` — закрытия, рейды, кейсы гонений, отобрание детей, психбольницы.

## Принцип точности

Не все точки имеют одинаковую точность:

- `region` — только региональная точка или heatmap;
- `city` — известен город, точный адрес не подтверждён / не нужен;
- `address` — публичный адрес из официального/полуофициального источника;
- `hidden` — точку нельзя публиковать точно.

## Источниковые уровни

- `A` — первичный документ / официальный список / бюллетень времени события / архив.
- `B` — научная статья / энциклопедия / проверяемая публикация.
- `C` — церковная память / поздний сайт / агрегатор.
- `D` — сигнал для поиска.
- `A/C` — первичный церковно-правозащитный источник, но нужна государственная/архивная сверка.

## Что нельзя делать

- Нельзя считать CSV полной картой церквей ЕХБ.
- Нельзя смешивать РС ЕХБ, МСЦ, независимых и исторические группы без фильтра `tradition`.
- Нельзя публиковать персональные данные современных пасторов, если они не опубликованы самой церковью/объединением.
- Нельзя строить точные адресные точки для незарегистрированных/чувствительных групп без публичного источника.
