## 1. Новые сквозные темы (добавить в драматургию файла 50)

К двум исходным нервам («происхождение: не импорт/не самозарождение» + «совесть») добавляются три:

3. **«Свой путь» в богословии.** Русский баптизм — не кальвинистский и не арминианский, а **синергийный** (файл 59). Это отдельная мысль, параллельная теме происхождения.
4. **Военный вопрос как сквозной нерв.** От 1905 через ПМВ, 1919/1923/1926, 1939, ВОВ — разные позиции, цена совести (файлы 51, 61). Проходит почти через все части.
5. **Отъезды и возвращение.** Эмиграция (меннониты 1874 → Америка; исход Эппа → Средняя Азия; высылки XX в.; Винс/«семёрка» → США) — и **обратный поток** обучения/миссии в наши дни (TMS/TMAI, файлы 58, 60). Дуга «потеря → сохранение → возвращение».

## 4. Премиальное оформление (спецификация фич — внедрять после рефакторинга)

По образцу «живых» серий сайта (Гилл/GBS-world, Нагорная), но единым компонентом серий:

**A. Навигация серии**
- единый sticky-навигатор частей (как Нагорная/GBS), переключение 1–10 + эпилог;
- прогресс чтения, «предыдущая/следующая часть», оглавление внутри части.

**B. Источниковая честность (визуально)**
- **бейдж уровня источника** у ключевых утверждений: ✓ первоисточник / ◐ вторично / ○ спорно (данные — файлы 27, 55);
- блок **«Источник vs память»** в каждой части (доказано документом / поздняя память / легенда);
- **сноски-голуби** для пояснений/оригиналов и **цифры** для ссылок на источники (по правилу владельца §9.12 AGENTS — голуби на справки, цифры на источники).

**C. Визуальные модули (после 100% рефакторинга — файл 32)**
- 2D SVG-схема в каждой части (маршрут/сеть/таймлайн/дерево решений);
- общая интерактивная карта/таймлайн с подсветкой фрагмента части;
- реальные изображения только с правами (media-ledger).

**D. «Карта различий» (интерактив в справочнике)**
- таблица позиций (сотериология, военный вопрос, регистрация, глоссолалия, омовение ног, алкоголь, имя) — файл 62 §3 как данные.

**E. Персональные карточки**
- единый компонент «герой»: портрет (с правами)/инициал, годы, одна-две строки, ссылка на разворот. Кандидаты: Воронин, Кальвейт, Деляков, Цимбал, Рябошапка, Ратушный, Вилер, Унгер, Пашков, Корф, Каргель, Проханов, Павлов, Мазаев, Крючков, Винс.

**F. Тон и палитра**
- 3 акта = 3 настроения (рассвет/день/ночь+искра), файл 50 §5;
- ambient-цитаты источников мелким шрифтом по краям (в духе главной), без перекрытий.
