## 3. Метод разведения (для следующего гео-pass)

1. Использовать **дореволюционные** административные привязки: уезд + губерния из самого протокола 1884 (Валькевич прил.№1 / Дородницын Doc. 323), а не современные районы.
2. Сверять по картам Херсонской / Таврической / Киевской / Екатеринославской губерний XIX в.
3. Для каждой точки фиксировать: историческое название → уезд/губерния → совр. название → координата → источник.
4. GeoNames/OSM — только как кандидат; финал — по совпадению уезда/губернии.

## 4. Что отдать в атлас прямо сейчас

Для диаграмм можно безопасно использовать **раздел 1** (A-/B+). Для раздела 2 — рисовать как «приблизительная зона» или подпись «точное село уточняется», но не ставить точную точку. Это прямо соответствует принципу атласа «нельзя делать псевдоточность там, где источник спорный».
