# Фото для будущей 3D-карты «Русский баптизм»

Эти изображения добавлены как локальные ассеты для будущей пересборки iframe-приложения `/konfessii/russkij-baptizm/_app/`. Цель — не декоративный фон, а историческая «фотопамять» узлов карты.

## Политика

- Хранить только изображения с понятным статусом: public domain / Wikimedia Commons / LOC / явное разрешение.
- Для спорных или современных фото — сначала фиксировать URL и статус в research, не тащить в проект без правовой ясности.
- В `_app/index.html` руками не вставлять: фото подключаются через исходники и пересборку.
