## timeline-integrated.js

Интегрированный таймлайн этапов — опциональный модуль, пока используется только
Павлом для richer stage navigation поверх стандартного движкового timeline.
⚠️ Известный нюанс: модуль выставляет `container.style.position='relative'`,
поэтому карта-контейнер должна иметь explicit `height` (см. фикс pavel `60c9bca6`).
